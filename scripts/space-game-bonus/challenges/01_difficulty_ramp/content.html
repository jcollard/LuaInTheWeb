New Concepts

  • Derived values — instead of changing spawn_interval in lots of places, calculate it from one thing (the level) every frame.
  • math.floor(x) — rounds down to a whole number. math.floor(7 / 5) is 1.
  • math.max(a, b) as a floor — math.max(0.4, x) never goes below 0.4, no matter how small x gets.
  • Constants — names in ALL_CAPS (like SCREEN_W) hold starting values that never change, so you can always reset back to them.
CHALLENGE Task 1: Add difficulty variables
In the GAME STATE section, add constants for the starting spawn interval (2.0), the fastest allowed spawn interval (0.4), the starting meteor speed (150), and how many points it takes to go up a level (5). Also add a level variable that starts at 1.
Look at how SCREEN_W and STAR_COUNT are written. Use the same ALL_CAPS style for your constants.
You need five lines: four local constants and local level = 1. Put them right after the spawn timer variables.
-- Difficulty
local START_SPAWN_INTERVAL = 2.0
local MIN_SPAWN_INTERVAL = 0.4
local START_METEOR_SPEED = 150
local POINTS_PER_LEVEL = 5
local level = 1
CHALLENGE Task 2: Calculate the level from the score
Each frame in update(), before the spawn timer, set level so that scores 0–4 are level 1, scores 5–9 are level 2, and so on.
Divide the score by POINTS_PER_LEVEL. For a score of 7 that gives 1.4. How do you turn that into a whole number?
math.floor(score / POINTS_PER_LEVEL) gives 0 for the first level. Add 1 so the first level is level 1.
level = math.floor(score / POINTS_PER_LEVEL) + 1
CHALLENGE Task 3: Make each level harder
Right after calculating the level, set spawn_interval and meteor_speed from it. Each level should take 0.2 seconds off the spawn interval (but never go below MIN_SPAWN_INTERVAL) and add 20 to the meteor speed.
On level 1 nothing should change, so use (level - 1) in your math. On level 1 that's 0.
The spawn interval is START_SPAWN_INTERVAL - (level - 1) * 0.2. Wrap that in math.max(MIN_SPAWN_INTERVAL, ...) so it can't get too small.
The meteor speed is START_METEOR_SPEED + (level - 1) * 20. There's no maximum — how long can you survive?
spawn_interval = math.max(MIN_SPAWN_INTERVAL, START_SPAWN_INTERVAL - (level - 1) * 0.2)
meteor_speed = START_METEOR_SPEED + (level - 1) * 20
CHALLENGE Task 4: Show the level and reset it
Draw "Level: " .. level in the HUD under the score (move the controls text down to make room). Then make reset_game() put level, spawn_interval, and meteor_speed back to their starting values.
The HUD lines are 20 pixels apart. Put the level at y = 30 and move the controls text to y = 50.
In reset_game(), use your constants: spawn_interval = START_SPAWN_INTERVAL and meteor_speed = START_METEOR_SPEED.
-- In draw(), HUD section
canvas.draw_text(10, 10, "Score: " .. score)
canvas.draw_text(10, 30, "Level: " .. level)
canvas.draw_text(10, 50, "Arrow keys: Move | SPACE: Shoot")

-- In reset_game()
level = 1
spawn_interval = START_SPAWN_INTERVAL
meteor_speed = START_METEOR_SPEED
