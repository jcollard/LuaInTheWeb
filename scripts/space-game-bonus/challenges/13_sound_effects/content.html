New Concepts

  • canvas.assets.load_sound(name, file) loads a sound file once, at the start, the same way you load images.
  • canvas.play_sound(name, volume) plays a sound one time. volume is optional and goes from 0 (silent) to 1 (full volume). Leave it out and you get full volume.
  • Events, not states: a sound should play at the moment something happens (the frame the laser fires), not every frame while something is true. Play a sound 60 times a second and you get a horrible buzz.
  • canvas.mute() turns all game sound off, canvas.unmute() turns it back on, and canvas.is_muted() tells you whether it's muted right now.
  • Browsers and sound: web browsers won't play any audio until you've clicked or pressed a key on the page. That stops websites blasting noise at you. If the game is silent at first, click on it and try again. That's a browser rule, not a bug in your code.

-- Load sounds
canvas.assets.load_sound("laser", "laser.ogg")
canvas.assets.load_sound("hit", "hit.ogg")
canvas.assets.load_sound("game_over", "game_over.ogg")
This tells the game to look in the sounds/ folder, then loads three sound files and gives each one a name. You'll use those names with canvas.play_sound(). Like images, sounds must be loaded before canvas.start(). If a sound doesn't play later, check that you spelled its name the same way in both places.
CHALLENGE Task 1: Pew pew!
Play the "laser" sound every time the ship fires. Play it at half volume (0.5).
You'll hear the laser far more often than any other sound. If everything is at full volume, the lasers drown out the important sounds like explosions. So give common sounds a lower volume and save full volume for rare ones.
Find the place in your code where a new laser is created. That line runs only on the one frame SPACE is pressed, so it's the right spot for a sound.
Inside the if canvas.is_key_pressed(canvas.keys.SPACE) then block, right after spawn_laser(...), add canvas.play_sound("laser", 0.5).
-- Fire laser
if canvas.is_key_pressed(canvas.keys.SPACE) then
    spawn_laser(ship_x + ship_w / 2 - laser_w / 2, ship_y)
    canvas.play_sound("laser", 0.5)
end

CHALLENGE Task 3: Play the game over sound once
Play the "game_over" sound when the ship crashes. It must play once, not over and over while the game over screen is showing. If you did Bonus 3: Lives & Invincibility or Bonus 10: Game States, the game ends on a different line, so look for the line that switches to the game over screen.
A tempting mistake is to put it in draw() inside if game_over then. But draw() runs every frame, so game_over is true on every frame of the game over screen. That would play the sound 60 times per second. Look for the one line that runs only on the frame the ship crashes.
Where does game_over change from false to true? That happens once per game.
In the ship vs meteor collision loop, add canvas.play_sound("game_over") right after game_over = true and before return. On the next frame, update() stops at if game_over then return end, so the collision code can't run again.
-- Ship vs meteor collision
for i, meteor in ipairs(meteors) do
    if check_collision(ship_x, ship_y, ship_w, ship_h,
                       meteor.x, meteor.y, meteor_w, meteor_h) then
        game_over = true
        canvas.play_sound("game_over")
        return
    end
end
CHALLENGE Task 4: Mute button
Pressing M should mute the game if it has sound, and unmute it if it's muted. It should work at any time, even on the game over screen. Show "Sound: ON" or "Sound: OFF" in the HUD, one line below your last HUD line, and add | M: Mute to the controls text.
This is a toggle: one key that flips between two states. Ask canvas.is_muted() which state you're in, then do the opposite.
In user_input(), the game over check has a return, so anything after it is skipped on the game over screen. Put the M check before it, right after local dt = .... If you did Bonus 10: Game States, put it at the top, before the state checks.
In the HUD, use if canvas.is_muted() then ... else ... end to choose which text to draw at y = 50, or one line below your last HUD line if other bonuses added more.
-- In user_input(), before the game over check
-- Mute / unmute (works any time, even on the game over screen)
if canvas.is_key_pressed(canvas.keys.M) then
    if canvas.is_muted() then
        canvas.unmute()
    else
        canvas.mute()
    end
end

-- In draw(), HUD section
canvas.draw_text(10, 30, "Arrow keys: Move | SPACE: Shoot | M: Mute")
if canvas.is_muted() then
    canvas.draw_text(10, 50, "Sound: OFF")
else
    canvas.draw_text(10, 50, "Sound: ON")
end

Going Further

  • If you've done other bonus challenges, the sounds/ folder also has powerup.ogg (for picking up a power-up), hurt.ogg (for losing a life), and enemy_laser.ogg (for enemy ships firing). Load them and play them at the right moments.
  • Make the hit sound a little different each time by playing it at a random volume between 0.6 and 1.0. (Hint: 0.6 + math.random() * 0.4. With nothing in the brackets, the random call gives a decimal between 0 and 1.)
  • Mash SPACE as fast as you can. Is it too noisy? Try the timer from Bonus 2: Fire Cooldown & Auto-Fire so you can only shoot every 0.2 seconds.
