New Concepts

  • Hit points (hp): a number stored in each meteor that says how many more hits it can take. A hit subtracts 1. At 0, it's destroyed.
  • Per-meteor flags: a true/false field like meteor.tough lets the same code treat some meteors differently.
  • Short effect timers: set meteor.flash = 0.1 (a tenth of a second) on a hit and count it down with dt. While it's above 0, draw the meteor differently.
  • canvas.set_global_alpha(a) makes everything drawn after it see-through. 1 is solid, 0 is invisible, and a number in between is partly see-through. It stays that way until you change it back, so always set it back to 1.
CHALLENGE Task 1: Load the grey meteor and add hp
With your other image-loading lines, load meteor_grey.png as "meteor_grey". Then change spawn_meteor() so every meteor gets three new fields: hp = 1, tough = false and flash = 0. One meteor in four should instead be tough: hp = 3 and tough = true.
Add the three fields to the meteor table with their normal values. Then, after the table is made but before table.insert, change them for the unlucky 1 in 4.
math.random(1, 4) gives 1, 2, 3 or 4. Checking if math.random(1, 4) == 1 then is true one time in four. Inside, set meteor.hp = 3 and meteor.tough = true.
-- With the other load_image lines
canvas.assets.load_image("meteor_grey", "meteor_grey.png")

local function spawn_meteor()
    local meteor = {
        x = math.random(0, SCREEN_W - meteor_w),
        y = -meteor_h,
        hp = 1,
        tough = false,
        flash = 0
    }
    -- 1 in 4 meteors is tough
    if math.random(1, 4) == 1 then
        meteor.hp = 3
        meteor.tough = true
    end
    table.insert(meteors, meteor)
end

CHALLENGE Task 3: Hits take away hp
Change the laser-vs-meteor collision. When a laser hits a meteor, the laser is always removed, and the meteor loses 1 hp. Only remove the meteor when its hp reaches 0. A destroyed tough meteor is worth 3 points; a normal one is worth 1.
Keep the break. Once table.remove(lasers, i) runs, lasers[i] is gone (or is now a different laser), so you need to stop checking meteors for it. The break has to happen whether the meteor was destroyed or not.
Inside the if check_collision(...), split the work in two. Some things happen on every hit: remove the laser and lose hp. Others only happen when hp is 0: remove the meteor and add score.
Writing meteors[j] over and over gets messy. Add local meteor = meteors[j] at the start of the inner loop and use meteor instead.
After table.remove(lasers, i) and meteor.hp = meteor.hp - 1, write if meteor.hp <= 0 then. Inside it, remove the meteor and add 3 or 1 to the score depending on meteor.tough. Put the break after that if's end.
-- Laser vs meteor collision
for i = #lasers, 1, -1 do
    for j = #meteors, 1, -1 do
        local meteor = meteors[j]
        if check_collision(lasers[i].x, lasers[i].y, laser_w, laser_h,
                           meteor.x, meteor.y, meteor_w, meteor_h) then
            -- Every hit uses up the laser and costs the meteor 1 hp
            table.remove(lasers, i)
            meteor.hp = meteor.hp - 1
            if meteor.hp <= 0 then
                table.remove(meteors, j)
                if meteor.tough then
                    score = score + 3
                else
                    score = score + 1
                end
            end
            break
        end
    end
end
CHALLENGE Task 4: Blink when hit
Right now a tough meteor looks the same after a hit as it did before. When a laser hits a meteor, set its flash to 0.1. In the meteor movement loop, count flash down by dt (but never below 0). When drawing, if flash is above 0, draw the meteor see-through with canvas.set_global_alpha(0.3).
Add meteor.flash = 0.1 next to meteor.hp = meteor.hp - 1. To count down without going below 0, use math.max(0, ...).
In the movement loop: meteors[i].flash = math.max(0, meteors[i].flash - dt).
When drawing: if meteor.flash > 0 then canvas.set_global_alpha(0.3) end, then draw_image, then always canvas.set_global_alpha(1) afterwards. Without that last line, the ship, the HUD and everything else turns see-through too. If your whole screen fades, check for this line.
-- In the laser vs meteor collision, after losing hp
meteor.flash = 0.1

-- In the meteor movement loop
meteors[i].flash = math.max(0, meteors[i].flash - dt)

-- In the meteor drawing loop
-- Blink (draw see-through) for a moment after being hit
if meteor.flash > 0 then
    canvas.set_global_alpha(0.3)
end
canvas.draw_image(image, meteor.x, meteor.y, meteor_w, meteor_h)
canvas.set_global_alpha(1)
CHALLENGE Task 5 (optional): Show the hp
In the meteor drawing loop, after canvas.set_global_alpha(1), draw one small red (255, 80, 80) rectangle (a “pip”) above each tough meteor for each hp it has left. Make each pip 8 pixels wide and 4 tall, 8 pixels above the meteor. Start the first pip 8 pixels in from the meteor's left edge, with pips 12 pixels apart.
Use a for loop from 1 to meteor.hp. Each time through the loop, draw one pip a bit further to the right.
Pip number p goes at x = meteor.x + 8 + (p - 1) * 12 and y = meteor.y - 8. Three pips then sit centered over the 48-pixel-wide meteor.
-- HP pips above tough meteors
if meteor.tough then
    canvas.set_color(255, 80, 80)
    for p = 1, meteor.hp do
        canvas.fill_rect(meteor.x + 8 + (p - 1) * 12, meteor.y - 8, 8, 4)
    end
end

Check Your Work

Run game.lua. You should see:

  • About one meteor in four is grey
  • Brown meteors still break with one hit and give 1 point
  • Grey meteors take three hits, and give 3 points when they break
  • Every laser disappears when it hits a meteor, even if the meteor survives
  • A meteor blinks briefly each time it's hit, and the rest of the screen never turns see-through
  • (Optional) Grey meteors show red pips that go down 3, 2, 1 as you hit them

Going Further

  • Make tough meteors fall a little slower than normal ones, so they're fair to shoot three times.
  • Instead of 1 in 4, make tough meteors more common as your score goes up.
  • Try a different hit effect: draw a white rectangle with low alpha over the meteor, or nudge it up a few pixels when hit.
