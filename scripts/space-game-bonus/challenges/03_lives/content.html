New Concepts

  • Lives — instead of ending the game on the first hit, count hits down from 3. The game is over only when lives reaches 0.
  • Invincibility timer — a countdown, just like the meteor spawn_timer but going down. While it's above 0, the ship can't be hit. Without it, one meteor could take all 3 lives in 3 frames!
  • Blinking — skip drawing the ship on some frames. math.floor(invincible_timer * 10) goes up by 1 every 0.1 seconds, and % 2 (remainder after dividing by 2) flips between 0 and 1. Draw on 1, hide on 0.
  • Drawing in a loop — for i = 1, lives do draws one icon per life, each one a bit further along.

CHALLENGE Task 2: Lose a life instead of losing the game
Change the ship vs meteor collision in update(). When the ship hits a meteor, remove that meteor and take away one life. Only set game_over when lives reaches 0.
Removing an item inside an ipairs loop is usually a bad idea. It's safe here because we break out of the loop right after, so the loop never looks at the shifted list.
Why remove the meteor? If it stays, it's still touching the ship next frame and would hit you again.
Inside the if check_collision(...): table.remove(meteors, i), then lives = lives - 1.
Then: if lives <= 0 then game_over = true return end. If the game isn't over, break so we only lose one life per frame.
for i, meteor in ipairs(meteors) do
    if check_collision(ship_x, ship_y, ship_w, ship_h,
                       meteor.x, meteor.y, meteor_w, meteor_h) then
        table.remove(meteors, i)
        lives = lives - 1
        if lives <= 0 then
            game_over = true
            return
        end
        break
    end
end
CHALLENGE Task 3: Add invincibility
After losing a life (but not on game over), start the invincibility timer. Each frame, count it down by dt (never below 0). While it's above 0, skip the ship vs meteor collision check completely.
Set invincible_timer = INVINCIBLE_TIME right before the break.
Count down just before the collision check: invincible_timer = math.max(0, invincible_timer - dt).
Wrap the whole collision for loop in if invincible_timer <= 0 then ... end.
-- Invincibility counts down to 0
invincible_timer = math.max(0, invincible_timer - dt)

-- Ship vs meteor collision (skipped while invincible)
if invincible_timer <= 0 then
    for i, meteor in ipairs(meteors) do
        if check_collision(ship_x, ship_y, ship_w, ship_h,
                           meteor.x, meteor.y, meteor_w, meteor_h) then
            table.remove(meteors, i)
            lives = lives - 1
            if lives <= 0 then
                game_over = true
                return
            end
            invincible_timer = INVINCIBLE_TIME
            break
        end
    end
end
CHALLENGE Task 4: Make the ship blink
In draw(), while the ship is invincible, hide it every other 0.1 seconds so it blinks. When it's not invincible, always draw it.
Make a local visible = true, set it to false when the ship should be hidden, and only call draw_image if visible.
Try it by hand: at invincible_timer = 1.53, math.floor(1.53 * 10) is 15, and 15 % 2 is 1. At 1.47 you get 14 % 2 = 0.
Hide the ship when invincible_timer > 0 and math.floor(invincible_timer * 10) % 2 == 0.
-- Ship (blinks while invincible: hidden every other 0.1 seconds)
local visible = true
if invincible_timer > 0 and math.floor(invincible_timer * 10) % 2 == 0 then
    visible = false
end
if visible then
    canvas.draw_image("ship", ship_x, ship_y, ship_w, ship_h)
end
