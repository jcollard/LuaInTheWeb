New Concepts

  • A state variable: wave_state holds a string, either "banner" (showing "WAVE 2") or "fighting". Your code checks it to decide what to do this frame.
  • Counting down what's left: each wave starts with a fixed number of meteors and enemies to spawn. Every spawn subtracts 1. When nothing is left to spawn and nothing is left on screen, the wave is over.
  • nil as "nothing here": there's only ever one boss, so instead of a list, boss is either a table or nil. Always check if boss ~= nil then before you touch boss.x.
  • % (remainder): wave % 3 is what's left over after dividing by 3. It's 0 on waves 3, 6, 9... so if wave % 3 == 0 means "every third wave".
  • Sideways velocity: a laser with vx = 150 moves 150 pixels right per second while it also falls. Three lasers with vx of -150, 0, and 150 make a spread.

if wave_state == "fighting" then
    spawn_timer = spawn_timer + dt

        spawn_meteor()
        wave_meteors_left = wave_meteors_left - 1

The boss table needs x, y, vx (its side speed, which switches between positive and negative to turn around), hp, max_hp, and a fire_timer for the next task. Start y at -boss_h so it flies in from above.
In start_wave(), wrap the two "left" lines in if wave % 3 == 0 then ... else ... end. The boss branch sets both counts to 0 and calls spawn_boss().

-- Boss (nil when there is no boss on screen)
local boss = nil
local boss_w = 200
local boss_h = 160
local boss_speed = 120
local BOSS_Y = 60
local BOSS_HP = 30
local BOSS_FIRE_INTERVAL = 1.2

-- With the other images
canvas.assets.load_image("boss", "boss.png")

-- Above start_wave()
local function spawn_boss()
    boss = {
        x = (SCREEN_W - boss_w) / 2,
        y = -boss_h,
        vx = boss_speed,
        hp = BOSS_HP,
        max_hp = BOSS_HP,
        fire_timer = BOSS_FIRE_INTERVAL
    }
end

-- start_wave() now has a boss wave
local function start_wave()
    wave = wave + 1
    wave_state = "banner"
    banner_timer = BANNER_TIME
    spawn_timer = 0
    enemy_spawn_timer = 0
    if wave % 3 == 0 then
        -- Boss wave: just the boss
        wave_meteors_left = 0
        wave_enemies_left = 0
        spawn_boss()
    else
        wave_meteors_left = 3 + wave * 2
        wave_enemies_left = wave
    end
end

-- In reset_game()
boss = nil
wave = 0
start_wave()

-- In update(), after the enemy loop
-- Move the boss: fly in from the top, then slide side to side and fire
if boss ~= nil then
    if boss.y < BOSS_Y then
        boss.y = boss.y + 80 * dt
    else
        boss.x = boss.x + boss.vx * dt
        if boss.x < 0 then
            boss.x = 0
            boss.vx = boss_speed
        elseif boss.x + boss_w > SCREEN_W then
            boss.x = SCREEN_W - boss_w
            boss.vx = -boss_speed
        end
    end
end

-- Next wave check now waits for the boss too
if wave_state == "fighting"
   and wave_meteors_left == 0 and wave_enemies_left == 0
   and #meteors == 0 and #enemies == 0 and boss == nil then
    start_wave()
end

-- In draw(), before the ship
-- Boss
if boss ~= nil then
    canvas.draw_image("boss", boss.x, boss.y, boss_w, boss_h)
end
