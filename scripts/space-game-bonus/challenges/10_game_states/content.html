New Concepts

  • Game states — real games are made of screens: a title screen, the game itself, a pause screen, a game over screen. The game is always in exactly one of them.
  • One string beats many booleans — with game_over, paused, and on_title as three separate true/false flags, nothing stops two of them being true at once. Paused and game over? On the title screen and paused? With one state variable, those impossible combinations simply can't happen.
  • if / elseif chains — if state == "title" then ... elseif state == "playing" then ... end runs exactly one branch, so each screen gets its own input, update, and drawing rules.
  • Custom fonts — canvas.assets.load_font(name, file) loads a font file, and canvas.set_font_family(name) switches to it. The normal font is called "monospace".

CHALLENGE Task 2: Input for each state
Rewrite user_input() as one if/elseif chain with a branch for each state:
  • title: ENTER calls reset_game() and switches to "playing"
  • playing: P switches to "paused"; the arrow keys and SPACE work like before
  • paused: P switches back to "playing"
  • game_over: ENTER switches to "title"
Why does game over go back to the title instead of straight into a new game? Now reset_game() is called in exactly one place: when you leave the title screen. Every new game starts the same way, and the player gets a breather between rounds.
Start with the shape: if state == "title" then … elseif state == "playing" then … elseif state == "paused" then … elseif state == "game_over" then … end. Then fill in each branch.
The movement and firing code moves inside the "playing" branch. The old if game_over then ... return end block at the top isn't needed anymore — the chain does that job.
Use is_key_pressed (not is_key_down) for P and ENTER. Otherwise holding P for a moment would flip between paused and playing every frame!
local function user_input()
    local dt = canvas.get_delta()

    if state == "title" then
        -- Start a fresh game
        if canvas.is_key_pressed(canvas.keys.ENTER) then
            reset_game()
            state = "playing"
        end

    elseif state == "playing" then
        -- Pause
        if canvas.is_key_pressed(canvas.keys.P) then
            state = "paused"
        end

        -- Ship movement
        if canvas.is_key_down(canvas.keys.LEFT) then ship_x = ship_x - ship_speed * dt end
        if canvas.is_key_down(canvas.keys.RIGHT) then ship_x = ship_x + ship_speed * dt end
        if canvas.is_key_down(canvas.keys.UP) then ship_y = ship_y - ship_speed * dt end
        if canvas.is_key_down(canvas.keys.DOWN) then ship_y = ship_y + ship_speed * dt end

        -- Fire laser
        if canvas.is_key_pressed(canvas.keys.SPACE) then
            spawn_laser(ship_x + ship_w / 2 - laser_w / 2, ship_y)
        end

    elseif state == "paused" then
        -- Unpause
        if canvas.is_key_pressed(canvas.keys.P) then
            state = "playing"
        end

    elseif state == "game_over" then
        -- Back to the title screen
        if canvas.is_key_pressed(canvas.keys.ENTER) then
            state = "title"
        end
    end
end

-- After init_stars()
local function move_stars(dt)
    for i, star in ipairs(stars) do
        star.y = star.y + star.speed * dt
        if star.y > SCREEN_H then
            star.x = math.random(0, SCREEN_W)
            star.y = -star.size
        end
    end
end

-- Top of update()
local dt = canvas.get_delta()

-- Title screen: only the stars move
if state == "title" then
    move_stars(dt)
    return
end

-- Paused or game over: nothing moves
if state ~= "playing" then return end

-- End of update() (replaces the old star loop)
-- Move stars
move_stars(dt)

Try font size 48 for the title at y = 200, size 24 for the start text at y = 320, and size 16 for the controls at y = 370. Add | P: Pause to the controls text in the HUD too.
local function draw_title()
    -- Game name in the sci-fi font
    canvas.set_font_family("future")
    canvas.set_font_size(48)
    canvas.set_color(255, 200, 50)
    local title = "SPACE SHOOTER"
    local title_w = canvas.get_text_width(title)
    canvas.draw_text((SCREEN_W - title_w) / 2, 200, title)

    -- Everything else in the normal font
    canvas.set_font_family("monospace")
    canvas.set_font_size(24)
    canvas.set_color(255, 255, 255)
    local start_text = "Press ENTER to start"
    local start_w = canvas.get_text_width(start_text)
    canvas.draw_text((SCREEN_W - start_w) / 2, 320, start_text)

    canvas.set_font_size(16)
    canvas.set_color(180, 180, 200)
    local help_text = "Arrow keys: Move | SPACE: Shoot | P: Pause"
    local help_w = canvas.get_text_width(help_text)
    canvas.draw_text((SCREEN_W - help_w) / 2, 370, help_text)
end

-- In draw(), right after the stars loop
