New Concepts

  • canvas.is_key_down vs canvas.is_key_pressed: is_key_pressed is true for only one frame when the key goes down. is_key_down is true every frame while the key is held. Right now you shoot with is_key_pressed, so you have to tap.
  • Cooldown timer: if you switch to is_key_down and change nothing else, you fire a laser every frame (60 per second!). A cooldown says “after you shoot, wait a bit before you can shoot again.”
  • The timer pattern, again: this is the same idea as the meteor spawn_timer. That one counts up to spawn_interval. This one counts down to 0. Both use dt so they work the same at any frame rate.
  • math.max(0, x) gives back the bigger of the two numbers, so it keeps a countdown from going below zero.
CHALLENGE Task 1: Add cooldown variables
In the GAME STATE section, right after the laser variables, add a constant FIRE_COOLDOWN for how many seconds to wait between shots (0.25). Also add a fire_timer variable that starts at 0.
fire_timer means “seconds left until you can fire again.” At 0, you're ready to shoot.
Use the ALL_CAPS style for the constant, like SCREEN_W and STAR_COUNT.
Two lines: local FIRE_COOLDOWN = 0.25 and local fire_timer = 0. Putting them right after the laser variables keeps laser things together.
-- Fire cooldown
local FIRE_COOLDOWN = 0.25
local fire_timer = 0
CHALLENGE Task 2: Count the timer down
In update(), right before the spawn timer, make fire_timer go down by dt each frame. It should stop at 0 and never go negative.
The spawn timer does spawn_timer = spawn_timer + dt. This timer counts the other way.
fire_timer - dt could become -0.01. Wrap it in math.max(0, ...) so the smallest it can be is 0.
-- Fire cooldown counts down to 0
fire_timer = math.max(0, fire_timer - dt)
CHALLENGE Task 3: Hold SPACE to auto-fire
Change the fire code in user_input() so that holding SPACE keeps firing, but only when the cooldown is finished. Every time a laser is fired, start the cooldown again.
Try swapping is_key_pressed for is_key_down first, without the timer. Hold SPACE and watch the solid wall of lasers. That's why we need a cooldown!
You need two things to be true before firing: SPACE is held down, and the timer has run out.
The condition is canvas.is_key_down(canvas.keys.SPACE) and fire_timer <= 0.
After calling spawn_laser(...), set fire_timer = FIRE_COOLDOWN. Now the next shot has to wait 0.25 seconds.
-- Fire laser (hold SPACE for auto-fire, once per cooldown)
if canvas.is_key_down(canvas.keys.SPACE) and fire_timer <= 0 then
    spawn_laser(ship_x + ship_w / 2 - laser_w / 2, ship_y)
    fire_timer = FIRE_COOLDOWN
end
CHALLENGE Task 4: Reset and update the controls text
Make reset_game() set fire_timer back to 0 so you can shoot right away in a new game. Then change the controls text in the HUD to say Hold SPACE: Shoot.
Every timer the game uses should be reset in reset_game(). Look at how spawn_timer is handled there.
Add fire_timer = 0 next to spawn_timer = 0. The HUD text is the last draw_text in the HUD section.
-- In reset_game()
spawn_timer = 0
fire_timer = 0

-- In draw(), HUD section
canvas.draw_text(10, 30, "Arrow keys: Move | Hold SPACE: Shoot")
CHALLENGE Task 5: Draw a cooldown bar (optional)
In draw(), right after drawing the ship, draw a thin yellow bar 2 pixels below the ship while the cooldown is running. Make it 4 pixels tall. Its width, bar_w, should match ship_w right after you fire and shrink to nothing when you're ready to shoot again.
When the ship is at the very bottom of the screen, there's no room below it, and the bar would be drawn off-screen. Store the bar's y position in bar_y, and keep it from going lower than SCREEN_H - 4.
fire_timer / FIRE_COOLDOWN is 1 right after firing and 0 when ready. Multiply that by ship_w to get the bar width.
Only draw it when fire_timer > 0. Its y position is ship_y + ship_h + 2, but math.min picks the smaller number, so math.min(ship_y + ship_h + 2, SCREEN_H - 4) stops it at the bottom edge.
Use canvas.set_color(255, 200, 50) and canvas.fill_rect(ship_x, bar_y, bar_w, 4).
-- Cooldown bar under the ship (shrinks as the cooldown runs out)
if fire_timer > 0 then
    local bar_w = ship_w * (fire_timer / FIRE_COOLDOWN)
    -- Stay on screen when the ship is at the bottom edge
    local bar_y = math.min(ship_y + ship_h + 2, SCREEN_H - 4)
    canvas.set_color(255, 200, 50)
    canvas.fill_rect(ship_x, bar_y, bar_w, 4)
end

Check Your Work

Run game.lua. You should see:

  • Holding SPACE fires a steady stream of lasers, about 4 per second
  • Lasers are evenly spaced, not a solid beam
  • Tapping SPACE quickly can't fire faster than the cooldown allows
  • A yellow bar under the ship shrinks after each shot (if you did Task 5)
  • After a game over and ENTER, you can shoot right away

Going Further

  • Try different values for FIRE_COOLDOWN. What feels best: 0.1, 0.25, or 0.5?
  • For a bigger challenge, add overheat. Firing adds heat, heat cools down over time, and if heat gets too high you can't shoot for 2 seconds.
  • Make the bar change color: red right after a shot, green when you're almost ready.
