New Concepts

  • Particles are lots of tiny, short-lived dots. Each one is a table in a list, like your stars. The difference: a particle has a velocity (vx, vy) so it can fly in any direction, and a life that counts down until it disappears.
  • Velocity is how fast something moves and in which direction. vx is how many pixels per second something moves sideways, and vy is how many it moves up or down. Each frame: p.x = p.x + p.vx * dt.
  • math.cos(angle) and math.sin(angle) turn a direction into its x part and y part. Pointing right, cos is 1 and sin is 0 (all sideways). Pointing straight down, cos is 0 and sin is 1 (all downward). In between, you get a mix. Multiply both by a speed and you have vx and vy.
  • Radians are how Lua measures angles, instead of degrees. A full circle is math.pi * 2 (about 6.28). So math.random() * math.pi * 2 is a random direction anywhere around the circle.
  • math.random() with no arguments gives a random decimal between 0 and 1 (like 0.73).
  • canvas.set_global_alpha(a) makes everything drawn after it see-through. 1 is solid, 0.5 is half see-through, 0 is invisible. It stays set until you change it.
  • canvas.fill_circle(x, y, radius) draws a filled circle centered at (x, y).
CHALLENGE Task 1: Write spawn_explosion
Add an empty particles list to the GAME STATE. Then write a function spawn_explosion(x, y, count) that adds count particles at (x, y). Each particle needs x, y, vx, vy, life, max_life, size, and a color (r, g, b). Pick a random direction and a random speed between 50 and 200 for each one. Give each particle a random life between 0.5 and 1 second and a random size from 2 to 4. For the color, keep red at 255 and blue at 50, and pick green randomly between 100 and 220.
Put the function above reset_game() in its own -- SPAWN EXPLOSION section, the same way spawn_meteor() has one. life and max_life start as the same number. life counts down; max_life remembers where it started so you can work out how faded the particle should be.
Look at init_stars() and generate_star(). You need a for i = 1, count do loop that builds a table and calls table.insert(particles, ...).
Inside the loop: local angle = math.random() * math.pi * 2 and local speed = math.random(50, 200). Then vx = math.cos(angle) * speed and vy = math.sin(angle) * speed.
For a life between half a second and one second: local life = 0.5 + math.random() * 0.5. For fiery colors, keep red at 255, blue at 50, and pick green randomly between 100 and 220 (orange to yellow).
-- In GAME STATE
-- Particles
local particles = {}

-- New section, above RESET GAME
local function spawn_explosion(x, y, count)
    for i = 1, count do
        local angle = math.random() * math.pi * 2
        local speed = math.random(50, 200)
        local life = 0.5 + math.random() * 0.5
        local particle = {
            x = x,
            y = y,
            vx = math.cos(angle) * speed,
            vy = math.sin(angle) * speed,
            life = life,
            max_life = life,
            size = math.random(2, 4),
            r = 255,
            g = math.random(100, 220),
            b = 50
        }
        table.insert(particles, particle)
    end
end

CHALLENGE Task 3: Move particles and let them die
In update(), loop over the particles. Move each one by its velocity, take dt off its life, and remove it when its life reaches 0.
This is your star-field loop with two changes: particles move in x and y, and instead of wrapping back to the top, they get removed. The tricky part is where it goes. Put this loop at the very top of update(), above if game_over then return end (you'll need to move local dt = canvas.get_delta() up too). If you did Bonus 10: Game States, put the loop above if state ~= "playing" then return end. In Task 5 your ship will explode on game over. If the particle loop were below the return, it would never run during game over and the explosion would freeze in mid-air.
You are removing items, so loop backwards: for i = #particles, 1, -1 do. Writing local p = particles[i] at the start saves a lot of typing.
Three updates: p.x = p.x + p.vx * dt, the same for y, and p.life = p.life - dt. Then if p.life <= 0 then table.remove(particles, i) end.
local function update()
    local dt = canvas.get_delta()

    -- Move particles and remove dead ones
    -- (before the game_over check, so explosions keep going)
    for i = #particles, 1, -1 do
        local p = particles[i]
        p.x = p.x + p.vx * dt
        p.y = p.y + p.vy * dt
        p.life = p.life - dt
        if p.life <= 0 then
            table.remove(particles, i)
        end
    end

    if game_over then return end

CHALLENGE Task 4: Draw fading particles
In draw(), after the ship, draw each particle as a filled circle in its color. Make it fade out: a brand-new particle is solid, and it gets more see-through as its life runs out. After the loop, set the global alpha back to 1.
Why reset? set_global_alpha doesn't switch itself off. If the last particle you drew was nearly invisible, the HUD, the game over screen, and next frame's background would all be drawn nearly invisible too.
How faded should it be? p.life / p.max_life is 1 when the particle is new and gets closer to 0 as it dies. That's exactly what set_global_alpha wants.
Inside an ipairs loop: canvas.set_global_alpha(p.life / p.max_life), then canvas.set_color(p.r, p.g, p.b), then canvas.fill_circle(p.x, p.y, p.size). After the loop: canvas.set_global_alpha(1).
-- Particles (fade out as their life runs down)
for i, p in ipairs(particles) do
    canvas.set_global_alpha(p.life / p.max_life)
    canvas.set_color(p.r, p.g, p.b)
    canvas.fill_circle(p.x, p.y, p.size)
end
canvas.set_global_alpha(1)
