New Concepts

  • Values that survive a reset — reset_game() puts everything back to the start. The high score is special: it must not be reset, or it would be forgotten every time you press ENTER.
  • Flags — a true/false variable that remembers something happened, like “this game beat the high score.”
  • require("localstorage") — saves small pieces of data in your browser, so they're still there after you close the page.
  • Saved values are strings — if you save the number 42, you get back the string "42". tonumber("42") turns it back into a number. If nothing was saved yet, you get nil, and tonumber(nil) or 0 gives 0.

Play a few games. The high score sticks around when you press ENTER... but if you stop the game and run it again, it's back to 0. Let's fix that.

TYPE THIS CODE Load the localstorage library
Where: at the top of the file, right after local canvas = require("canvas")
local localstorage = require("localstorage")
localstorage.set_prefix("space_shooter_")
Your browser keeps one storage area for every program on this site. The prefix gets added to the front of every key, so our "high_score" is really saved as "space_shooter_high_score" and won't mix with other games' high scores.
CHALLENGE Task 5: Load the saved high score
Replace local high_score = 0 so it starts with the value saved under the key "high_score", or 0 if nothing has been saved yet.
localstorage.get_item(key) returns a string, or nil if that key was never saved.
First get the saved value into a variable: local saved = localstorage.get_item("high_score").
saved might be "42" or nil. tonumber(saved) turns "42" into 42 and nil into nil. Then or 0 picks 0 when it's nil.
-- High score (loaded from storage; saved values are strings)
local saved = localstorage.get_item("high_score")
local high_score = tonumber(saved) or 0
local new_high_score = false
CHALLENGE Task 6: Save a new high score
When the player beats the high score, save it with localstorage.set_item under the same key.
You only need to save when the high score changes. You already have an if for that from Task 2.
Add localstorage.set_item("high_score", high_score) inside that if. The number is turned into a string for you when it's saved.
game_over = true
-- Check for a new high score and save it
if score > high_score then
    high_score = score
    new_high_score = true
    localstorage.set_item("high_score", high_score)
end
return
