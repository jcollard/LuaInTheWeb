SPACE SHOOTER — BONUS CHALLENGES

★★ ENTITIESBonus 8: Power-Ups

Destroyed meteors sometimes drop a power-up: triple shot, a shield, or a speed boost.

Before you start
  • Prerequisites: None — start from your finished Part 7 game.
  • New files for this challenge: images/powerup_triple.png, images/powerup_shield.png, images/powerup_speed.png, images/shield.png
  • Make a backup copy of your game.lua first, so you can always go back.
  • Bonus challenges give you less help than the main guide. Work out where each piece of code goes, and use the hints if you get stuck.

New Concepts

  • A "kind" field lets one list hold different things. All three power-ups fall and get collected the same way. Instead of three lists, use one list where each power-up has kind = "triple", "shield", or "speed". Check the kind only when it matters.
  • Picking from a list: POWERUP_KINDS[math.random(1, #POWERUP_KINDS)] picks a random item from a list.
  • Building a name with ..: if you load images named "powerup_triple", "powerup_shield", and "powerup_speed", then "powerup_" .. p.kind is always the right image name.
  • Countdown timers: set triple_timer = 5 to switch triple shot on, and subtract dt each frame. While it's above 0, the effect is on.
  • Default values with or: vx or 0 means "use vx, but if nobody passed it in (it's nil), use 0". This lets spawn_laser(x, y) keep working exactly as before.
  • string.format("%.1f", t) turns a number into text with exactly one digit after the decimal point. 4.2371 becomes "4.2".
CHALLENGE Task 1: Power-up state and images
In GAME STATE, add an empty powerups list. Then add the power-up settings: powerup_size (34), powerup_speed (100), POWERUP_CHANCE (5, meaning 1 in 5), POWERUP_DURATION (5 seconds), and POWERUP_KINDS, a list of the three kinds. Add two timers that start at 0 (triple_timer, speed_timer), and shield_active, which starts as false. Then load the four new images: powerup_triple.png, powerup_shield.png, powerup_speed.png, and shield.png.
The shield is different from the other two: it has no timer. It stays on until a meteor hits you, then it's used up. That makes it feel like an extra life you have to earn. (If you'd rather it run out after a few seconds, give it a timer like the others.)
Look at how the meteor variables are grouped. Write a -- Power-ups block the same way. The kinds list is {"triple", "shield", "speed"}.
Name each power-up image "powerup_" plus its kind, so "powerup_" .. kind works later. Load them next to the ship, laser, and meteor images.
-- Power-ups
local powerups = {}

local powerup_speed = 100
local POWERUP_CHANCE = 5       -- 1 in 5 destroyed meteors drops one
local POWERUP_DURATION = 5     -- seconds
local POWERUP_KINDS = {"triple", "shield", "speed"}
local triple_timer = 0
local speed_timer = 0
local shield_active = false

-- With the other images
canvas.assets.load_image("powerup_triple", "powerup_triple.png")

CHALLENGE Task 2: Drop power-ups from meteors
Write spawn_powerup(x, y) that adds a power-up of a random kind to the list. Put it in a new section above RESET GAME. Then, when a laser destroys a meteor, give it a 1 in POWERUP_CHANCE chance of dropping a power-up centered where the meteor was. If you did Bonus 5: Meteor Variety, use each meteor's own w and h instead of meteor_w and meteor_h.
spawn_powerup is built like spawn_meteor, but the table has x, y, and kind = POWERUP_KINDS[math.random(1, #POWERUP_KINDS)].
"1 in 5" is math.random(1, POWERUP_CHANCE) == 1. Do it before table.remove(meteors, j), while you can still read the meteor's position.
To center the power-up on the meteor: meteors[j].x + meteor_w / 2 - powerup_size / 2. That's "meteor's center, then back up half a power-up". Same for y.
-- New section, above RESET GAME
local function spawn_powerup(x, y)
    local powerup = {
        x = x,
        y = y,
        kind = POWERUP_KINDS[math.random(1, #POWERUP_KINDS)]
    }
    table.insert(powerups, powerup)
end

-- In the laser vs meteor collision
-- Sometimes drop a power-up where the meteor was
if math.random(1, POWERUP_CHANCE) == 1 then
    spawn_powerup(meteors[j].x + meteor_w / 2 - powerup_size / 2,
                  meteors[j].y + meteor_h / 2 - powerup_size / 2)
end
table.remove(meteors, j)
CHALLENGE Task 3: Fall, collect, and count down
In update(), before the ship vs meteor collision: count both timers down (never below 0). Then move every power-up down. If the ship touches one, switch on its effect and remove it. If it falls off the bottom, remove it.
math.max(0, triple_timer - dt) subtracts dt but stops at 0.
Loop backwards with for i = #powerups, 1, -1 do. Use check_collision with the ship and powerup_size for both width and height.
Use if ... elseif ... on p.kind: triple sets triple_timer = POWERUP_DURATION, speed sets speed_timer = POWERUP_DURATION, shield sets shield_active = true. Use elseif p.y > SCREEN_H for falling off, so you never remove the same power-up twice.
-- Power-up timers count down to 0
triple_timer = math.max(0, triple_timer - dt)
speed_timer = math.max(0, speed_timer - dt)

-- Move power-ups, collect them, or remove off-screen ones
for i = #powerups, 1, -1 do
    local p = powerups[i]
    p.y = p.y + powerup_speed * dt
    if check_collision(ship_x, ship_y, ship_w, ship_h,
                       p.x, p.y, powerup_size, powerup_size) then
        if p.kind == "triple" then
            triple_timer = POWERUP_DURATION
        elseif p.kind == "speed" then
            speed_timer = POWERUP_DURATION
        elseif p.kind == "shield" then
            shield_active = true
        end
        table.remove(powerups, i)
    elseif p.y > SCREEN_H then
        table.remove(powerups, i)
    end
end
CHALLENGE Task 4: Triple shot
Give lasers a sideways speed, vx. Add a third parameter to spawn_laser(x, y, vx) that defaults to 0, and move each laser sideways by vx every frame. Then, while triple_timer is above 0, pressing SPACE fires two extra lasers: one drifting left (vx = -150) and one drifting right (vx = 150).
In spawn_laser, add vx = vx or 0 to the laser table. Your existing spawn_laser(x, y) call still works: vx is nil, so it becomes 0.
In the "Move lasers" loop, add lasers[i].x = lasers[i].x + lasers[i].vx * dt. If you get an error about a nil value on this line, check the vx line in spawn_laser.
When firing, save the starting x in local laser_x = ship_x + ship_w / 2 - laser_w / 2 so you don't type it three times. Fire the normal laser, then if triple_timer > 0 then fire the two angled ones.
-- spawn_laser
local function spawn_laser(x, y, vx)
    local laser = {
        x = x,
        y = y,
        vx = vx or 0
    }
    table.insert(lasers, laser)
end

-- In update(), "Move lasers" loop
lasers[i].x = lasers[i].x + lasers[i].vx * dt
lasers[i].y = lasers[i].y - laser_speed * dt

-- In user_input()
-- Fire laser (three spreading lasers with triple shot)
if canvas.is_key_pressed(canvas.keys.SPACE) then
    local laser_x = ship_x + ship_w / 2 - laser_w / 2
    spawn_laser(laser_x, ship_y)
    if triple_timer > 0 then
        spawn_laser(laser_x, ship_y, -150)
        spawn_laser(laser_x, ship_y, 150)
    end
end
CHALLENGE Task 5: Speed boost and shield
While speed_timer is above 0, the ship moves twice as fast. When a meteor hits the ship while shield_active is true, the shield is used up. The meteor is destroyed and the game keeps going. (If you did Bonus 10: Game States, the else part sets state = "game_over" instead of game_over = true. Keep anything else your game already does when it ends, like the game over sound from Bonus 13: Sound Effects, in the else part too.)
For speed, don't change ship_speed itself. If you double it, you have to remember to halve it again later (and in reset_game()). Instead, work out a local speed each frame and move with that.
At the top of the movement code in user_input(): local speed = ship_speed, then if speed_timer > 0 then speed = ship_speed * 2 end. Use speed in all four movement lines.
The ship vs meteor loop now removes meteors, so it must loop backwards like the others: for i = #meteors, 1, -1 do, using meteors[i].x instead of meteor.x.
Inside the collision: if shield_active then set it to false and table.remove(meteors, i), else do the old game_over = true and return.
-- In user_input()
-- Speed boost doubles the ship's speed
local speed = ship_speed
if speed_timer > 0 then
    speed = ship_speed * 2
end

-- Ship movement
if canvas.is_key_down(canvas.keys.LEFT) then ship_x = ship_x - speed * dt end
if canvas.is_key_down(canvas.keys.RIGHT) then ship_x = ship_x + speed * dt end
if canvas.is_key_down(canvas.keys.UP) then ship_y = ship_y - speed * dt end
if canvas.is_key_down(canvas.keys.DOWN) then ship_y = ship_y + speed * dt end

-- In update()
-- Ship vs meteor collision (the shield saves you once)
for i = #meteors, 1, -1 do
    if check_collision(ship_x, ship_y, ship_w, ship_h,
                       meteors[i].x, meteors[i].y, meteor_w, meteor_h) then
        if shield_active then
            shield_active = false
            table.remove(meteors, i)
        else
            game_over = true
            return
        end
    end
end

Check Your Work

Run game.lua. You should see:

  • About one in five meteors you shoot drops a star, shield, or lightning bolt that slowly falls
  • Missed power-ups fall off the bottom of the screen
  • Catching the star fires three lasers in a fan for 5 seconds, and the HUD counts down Triple Shot
  • Catching the bolt makes the ship twice as fast for 5 seconds
  • Catching the shield puts a bubble around the ship. The next meteor that hits you is destroyed and the bubble disappears. The one after that ends the game.
  • After pressing ENTER to restart, no power-ups are active

Going Further

  • Make the side lasers lean the way they travel: use canvas.save(), canvas.translate(), and canvas.rotate() when drawing a laser with vx that isn't 0.
  • Make the shield bubble blink during its last second, or give the shield a timer too. Which is more fun?
  • Invent a fourth power-up, like one that slows every meteor down for a few seconds. Add its kind to POWERUP_KINDS and pick an image from images/.

-- ============================================================
-- Space Shooter — Bonus 8: Power-Ups
-- Grab falling power-ups for triple shot, a shield, or extra speed!
-- ============================================================

local canvas = require("canvas")
canvas.assets.add_path("images")
canvas.set_size(800, 600)

local SCREEN_W = 800
local SCREEN_H = 600

-- ============================================================
-- GAME STATE
-- ============================================================

-- Ship
local ship_x = 370
local ship_y = 500
local ship_w = 60
local ship_h = 48
local ship_speed = 300

-- Lasers
local lasers = {}
local laser_w = 9
local laser_h = 30
local laser_speed = 500

-- Meteors
local meteors = {}
local meteor_w = 48
local meteor_h = 48
local meteor_speed = 150

-- Spawn timer
local spawn_timer = 0
local spawn_interval = 2.0

-- Score
local score = 0

-- Game over
local game_over = false

-- Stars
local stars = {}
local STAR_COUNT = 60

-- Power-ups
local powerups = {}
local powerup_size = 34
local powerup_speed = 100
local POWERUP_CHANCE = 5       -- 1 in 5 destroyed meteors drops one
local POWERUP_DURATION = 5     -- seconds
local POWERUP_KINDS = {"triple", "shield", "speed"}
local triple_timer = 0
local speed_timer = 0
local shield_active = false

-- Load images
canvas.assets.load_image("ship", "blue_ship.png")
canvas.assets.load_image("laser", "laser.png")
canvas.assets.load_image("meteor", "meteor.png")
canvas.assets.load_image("powerup_triple", "powerup_triple.png")
canvas.assets.load_image("powerup_shield", "powerup_shield.png")
canvas.assets.load_image("powerup_speed", "powerup_speed.png")
canvas.assets.load_image("shield", "shield.png")

-- ============================================================
-- GENERATE STAR
-- ============================================================

local function generate_star()
    local size = math.random(1, 3)
    local speed = size * 30
    local brightness = size * 60 + 40
    return {
        x = math.random(0, SCREEN_W),
        y = math.random(0, SCREEN_H),
        size = size,
        speed = speed,
        brightness = brightness
    }
end

-- ============================================================
-- INIT STARS
-- ============================================================

local function init_stars()
    stars = {}
    for i = 1, STAR_COUNT do
        table.insert(stars, generate_star())
    end
end

init_stars()

-- ============================================================
-- COLLISION DETECTION
-- ============================================================

local function check_collision(a_x, a_y, a_w, a_h, b_x, b_y, b_w, b_h)
    return a_x < b_x + b_w
       and a_x + a_w > b_x
       and a_y < b_y + b_h
       and a_y + a_h > b_y
end

-- ============================================================
-- SPAWN METEOR
-- ============================================================

local function spawn_meteor()
    local meteor = {
        x = math.random(0, SCREEN_W - meteor_w),
        y = -meteor_h
    }
    table.insert(meteors, meteor)
end

-- ============================================================
-- SPAWN LASER
-- ============================================================

local function spawn_laser(x, y, vx)
    local laser = {
        x = x,
        y = y,
        vx = vx or 0
    }
    table.insert(lasers, laser)
end

-- ============================================================
-- SPAWN POWER-UP
-- ============================================================

local function spawn_powerup(x, y)
    local powerup = {
        x = x,
        y = y,
        kind = POWERUP_KINDS[math.random(1, #POWERUP_KINDS)]
    }
    table.insert(powerups, powerup)
end

-- ============================================================
-- RESET GAME
-- ============================================================

local function reset_game()
    ship_x = 370
    ship_y = 500
    lasers = {}
    meteors = {}
    spawn_timer = 0
    score = 0
    game_over = false
    powerups = {}
    triple_timer = 0
    speed_timer = 0
    shield_active = false
    init_stars()
end

-- ============================================================
-- USER INPUT
-- ============================================================

local function user_input()
    local dt = canvas.get_delta()

    -- Restart on ENTER when game is over
    if game_over then
        if canvas.is_key_pressed(canvas.keys.ENTER) then
            reset_game()
        end
        return
    end

    -- Speed boost doubles the ship's speed
    local speed = ship_speed
    if speed_timer > 0 then
        speed = ship_speed * 2
    end

    -- Ship movement
    if canvas.is_key_down(canvas.keys.LEFT) then ship_x = ship_x - speed * dt end
    if canvas.is_key_down(canvas.keys.RIGHT) then ship_x = ship_x + speed * dt end
    if canvas.is_key_down(canvas.keys.UP) then ship_y = ship_y - speed * dt end
    if canvas.is_key_down(canvas.keys.DOWN) then ship_y = ship_y + speed * dt end

    -- Fire laser (three spreading lasers with triple shot)
    if canvas.is_key_pressed(canvas.keys.SPACE) then
        local laser_x = ship_x + ship_w / 2 - laser_w / 2
        spawn_laser(laser_x, ship_y)
        if triple_timer > 0 then
            spawn_laser(laser_x, ship_y, -150)
            spawn_laser(laser_x, ship_y, 150)
        end
    end
end

-- ============================================================
-- UPDATE
-- ============================================================

local function update()
    if game_over then return end

    local dt = canvas.get_delta()

    -- Clamp ship to screen
    ship_x = math.max(0, math.min(SCREEN_W - ship_w, ship_x))
    ship_y = math.max(0, math.min(SCREEN_H - ship_h, ship_y))

    -- Move lasers and remove off-screen ones
    for i = #lasers, 1, -1 do
        lasers[i].x = lasers[i].x + lasers[i].vx * dt
        lasers[i].y = lasers[i].y - laser_speed * dt
        if lasers[i].y + laser_h < 0 then
            table.remove(lasers, i)
        end
    end

    -- Spawn timer
    spawn_timer = spawn_timer + dt
    if spawn_timer >= spawn_interval then
        spawn_meteor()
        spawn_timer = 0
    end

    -- Move meteors and remove off-screen ones
    for i = #meteors, 1, -1 do
        meteors[i].y = meteors[i].y + meteor_speed * dt
        if meteors[i].y > SCREEN_H then
            table.remove(meteors, i)
        end
    end

    -- Laser vs meteor collision
    for i = #lasers, 1, -1 do
        for j = #meteors, 1, -1 do
            if check_collision(lasers[i].x, lasers[i].y, laser_w, laser_h,
                               meteors[j].x, meteors[j].y, meteor_w, meteor_h) then
                -- Sometimes drop a power-up where the meteor was
                if math.random(1, POWERUP_CHANCE) == 1 then
                    spawn_powerup(meteors[j].x + meteor_w / 2 - powerup_size / 2,
                                  meteors[j].y + meteor_h / 2 - powerup_size / 2)
                end
                table.remove(meteors, j)
                table.remove(lasers, i)
                score = score + 1
                break
            end
        end
    end

    -- Power-up timers count down to 0
    triple_timer = math.max(0, triple_timer - dt)
    speed_timer = math.max(0, speed_timer - dt)

    -- Move power-ups, collect them, or remove off-screen ones
    for i = #powerups, 1, -1 do
        local p = powerups[i]
        p.y = p.y + powerup_speed * dt
        if check_collision(ship_x, ship_y, ship_w, ship_h,
                           p.x, p.y, powerup_size, powerup_size) then
            if p.kind == "triple" then
                triple_timer = POWERUP_DURATION
            elseif p.kind == "speed" then
                speed_timer = POWERUP_DURATION
            elseif p.kind == "shield" then
                shield_active = true
            end
            table.remove(powerups, i)
        elseif p.y > SCREEN_H then
            table.remove(powerups, i)
        end
    end

    -- Ship vs meteor collision (the shield saves you once)
    for i = #meteors, 1, -1 do
        if check_collision(ship_x, ship_y, ship_w, ship_h,
                           meteors[i].x, meteors[i].y, meteor_w, meteor_h) then
            if shield_active then
                shield_active = false
                table.remove(meteors, i)
            else
                game_over = true
                return
            end
        end
    end

    -- Move stars
    for i, star in ipairs(stars) do
        star.y = star.y + star.speed * dt
        if star.y > SCREEN_H then
            star.x = math.random(0, SCREEN_W)
            star.y = -star.size
        end
    end
end

-- ============================================================
-- DRAW
-- ============================================================

local function draw()
    canvas.clear()

    -- Dark space background
    canvas.set_color(10, 10, 30)
    canvas.fill_rect(0, 0, SCREEN_W, SCREEN_H)

    -- Stars
    for i, star in ipairs(stars) do
        canvas.set_color(star.brightness, star.brightness, star.brightness)
        canvas.fill_rect(star.x, star.y, star.size, star.size)
    end

    -- Lasers
    for i, laser in ipairs(lasers) do
        canvas.draw_image("laser", laser.x, laser.y, laser_w, laser_h)
    end

    -- Meteors
    for i, meteor in ipairs(meteors) do
        canvas.draw_image("meteor", meteor.x, meteor.y, meteor_w, meteor_h)
    end

    -- Power-ups ("powerup_" .. "triple" is "powerup_triple")
    for i, p in ipairs(powerups) do
        canvas.draw_image("powerup_" .. p.kind, p.x, p.y, powerup_size, powerup_size)
    end

    -- Ship
    canvas.draw_image("ship", ship_x, ship_y, ship_w, ship_h)

    -- Shield bubble, centered on the ship
    if shield_active then
        local shield_w = ship_w + 20
        local shield_h = ship_h + 20
        canvas.draw_image("shield", ship_x + ship_w / 2 - shield_w / 2,
                          ship_y + ship_h / 2 - shield_h / 2, shield_w, shield_h)
    end

    -- HUD
    canvas.set_color(255, 255, 255)
    canvas.set_font_size(16)
    canvas.draw_text(10, 10, "Score: " .. score)
    canvas.draw_text(10, 30, "Arrow keys: Move | SPACE: Shoot")

    -- Active power-ups, one line each
    local hud_y = 50
    if triple_timer > 0 then
        canvas.draw_text(10, hud_y, "Triple Shot: " .. string.format("%.1f", triple_timer))
        hud_y = hud_y + 20
    end
    if speed_timer > 0 then
        canvas.draw_text(10, hud_y, "Speed: " .. string.format("%.1f", speed_timer))
        hud_y = hud_y + 20
    end
    if shield_active then
        canvas.draw_text(10, hud_y, "Shield: ON")
    end

    -- Game over overlay
    if game_over then
        -- Dark overlay
        canvas.set_color(0, 0, 0, 180)
        canvas.fill_rect(0, 0, SCREEN_W, SCREEN_H)

        -- "GAME OVER" text (red)
        canvas.set_font_size(48)
        canvas.set_color(255, 50, 50)
        local title = "GAME OVER"
        local title_w = canvas.get_text_width(title)
        canvas.draw_text((SCREEN_W - title_w) / 2, SCREEN_H / 2 - 60, title)

        -- Score text (white)
        canvas.set_font_size(24)
        canvas.set_color(255, 255, 255)
        local score_text = "Score: " .. score
        local score_w = canvas.get_text_width(score_text)
        canvas.draw_text((SCREEN_W - score_w) / 2, SCREEN_H / 2, score_text)

        -- Restart prompt (white)
        local restart_text = "Press ENTER to restart"
        local restart_w = canvas.get_text_width(restart_text)
        canvas.draw_text((SCREEN_W - restart_w) / 2, SCREEN_H / 2 + 40, restart_text)
    end
end

-- ============================================================
-- GAME LOOP
-- ============================================================

local function game()
    user_input()
    update()
    draw()
end

canvas.tick(game)
canvas.start()
