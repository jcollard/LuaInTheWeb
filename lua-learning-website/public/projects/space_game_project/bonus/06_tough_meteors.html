SPACE SHOOTER — BONUS CHALLENGES

★★ ENTITIESBonus 6: Tough Meteors

Some meteors are made of tougher rock. They take three hits to destroy, blink when hit, and are worth more points.

Before you start
  • Prerequisites: None — start from your finished Part 7 game.
  • New files for this challenge: images/meteor_grey.png
  • Make a backup copy of your game.lua first, so you can always go back.
  • Bonus challenges give you less help than the main guide. Work out where each piece of code goes, and use the hints if you get stuck.

New Concepts

  • Hit points (hp) — a number stored in each meteor that says how many more hits it can take. A hit subtracts 1. At 0, it's destroyed.
  • Per-meteor flags — a true/false field like meteor.tough lets the same code treat some meteors differently.
  • Short effect timers — set meteor.flash = 0.1 on a hit and count it down with dt. While it's above 0, draw the meteor differently.
  • canvas.set_global_alpha(a) — makes everything drawn after it see-through. 1 is solid, 0 is invisible. It stays that way until you change it back, so always set it back to 1.
CHALLENGE Task 1: Load the grey meteor and add hp
Load meteor_grey.png as "meteor_grey". Then change spawn_meteor() so every meteor gets three new fields: hp = 1, tough = false and flash = 0. One meteor in four should instead be tough: hp = 3 and tough = true.
Add the three fields to the meteor table with their normal values. Then, after the table is made but before table.insert, change them for the unlucky 1 in 4.
math.random(1, 4) gives 1, 2, 3 or 4. Checking if math.random(1, 4) == 1 then is true one time in four. Inside, set meteor.hp = 3 and meteor.tough = true.
-- With the other load_image lines
canvas.assets.load_image("meteor_grey", "meteor_grey.png")

local function spawn_meteor()
    local meteor = {
        x = math.random(0, SCREEN_W - meteor_w),
        y = -meteor_h,
        hp = 1,
        tough = false,
        flash = 0
    }
    -- 1 in 4 meteors is tough
    if math.random(1, 4) == 1 then
        meteor.hp = 3
        meteor.tough = true
    end
    table.insert(meteors, meteor)
end
CHALLENGE Task 2: Draw tough meteors in grey
In the meteor drawing loop, draw tough meteors with the "meteor_grey" image and normal meteors with "meteor".
Make a local variable for the image name before you call draw_image.
Start with local image = "meteor". If meteor.tough is true, change it to "meteor_grey". Then pass image to canvas.draw_image instead of "meteor".
for i, meteor in ipairs(meteors) do
    local image = "meteor"
    if meteor.tough then
        image = "meteor_grey"
    end
    canvas.draw_image(image, meteor.x, meteor.y, meteor_w, meteor_h)
end
CHALLENGE Task 3: Hits take away hp
Change the laser-vs-meteor collision. When a laser hits a meteor, the laser is always removed, and the meteor loses 1 hp. Only remove the meteor when its hp reaches 0. A destroyed tough meteor is worth 3 points; a normal one is worth 1.
Keep the break! Once table.remove(lasers, i) runs, lasers[i] is gone (or is now a different laser), so we must stop checking meteors for it. The break has to happen whether the meteor was destroyed or not.
Inside the if check_collision(...), split the work in two: things that happen on every hit (remove the laser, lose hp), and things that only happen when hp is 0 (remove the meteor, add score).
Writing meteors[j] over and over gets messy. Add local meteor = meteors[j] at the start of the inner loop and use meteor instead.
After table.remove(lasers, i) and meteor.hp = meteor.hp - 1, write if meteor.hp <= 0 then. Inside it, remove the meteor and add 3 or 1 to the score depending on meteor.tough. Put the break after that if's end.
-- Laser vs meteor collision
for i = #lasers, 1, -1 do
    for j = #meteors, 1, -1 do
        local meteor = meteors[j]
        if check_collision(lasers[i].x, lasers[i].y, laser_w, laser_h,
                           meteor.x, meteor.y, meteor_w, meteor_h) then
            -- Every hit uses up the laser and costs the meteor 1 hp
            table.remove(lasers, i)
            meteor.hp = meteor.hp - 1
            if meteor.hp <= 0 then
                table.remove(meteors, j)
                if meteor.tough then
                    score = score + 3
                else
                    score = score + 1
                end
            end
            break
        end
    end
end
CHALLENGE Task 4: Blink when hit
Right now you can't tell if a tough meteor was hit. When a laser hits a meteor, set its flash to 0.1. In the meteor movement loop, count flash down by dt (but never below 0). When drawing, if flash is above 0, draw the meteor see-through with canvas.set_global_alpha(0.3).
Add meteor.flash = 0.1 next to meteor.hp = meteor.hp - 1. To count down without going below 0, use math.max(0, ...).
In the movement loop: meteors[i].flash = math.max(0, meteors[i].flash - dt).
When drawing: if meteor.flash > 0 then canvas.set_global_alpha(0.3) end, then draw_image, then always canvas.set_global_alpha(1) afterwards. If you forget that last line, the ship, the HUD and everything else turns see-through too!
-- In the laser vs meteor collision, after losing hp
meteor.flash = 0.1

-- In the meteor movement loop
meteors[i].flash = math.max(0, meteors[i].flash - dt)

-- In the meteor drawing loop
-- Blink (draw see-through) for a moment after being hit
if meteor.flash > 0 then
    canvas.set_global_alpha(0.3)
end
canvas.draw_image(image, meteor.x, meteor.y, meteor_w, meteor_h)
canvas.set_global_alpha(1)
CHALLENGE Task 5 (optional): Show the hp
Above each tough meteor, draw one small red rectangle (a “pip”) for each hp it has left. Make each pip 8 pixels wide and 4 tall, 8 pixels above the meteor, with pips 12 pixels apart.
Use a for loop from 1 to meteor.hp. Each time round the loop, draw one pip a bit further to the right.
Pip number p goes at x = meteor.x + 8 + (p - 1) * 12 and y = meteor.y - 8. Three pips then sit centered over the 48-pixel-wide meteor.
-- HP pips above tough meteors
if meteor.tough then
    canvas.set_color(255, 80, 80)
    for p = 1, meteor.hp do
        canvas.fill_rect(meteor.x + 8 + (p - 1) * 12, meteor.y - 8, 8, 4)
    end
end

Check Your Work

Run game.lua. You should see:

  • About one meteor in four is grey
  • Brown meteors still break with one hit and give 1 point
  • Grey meteors take three hits, and give 3 points when they break
  • Every laser disappears when it hits a meteor, even if the meteor survives
  • A meteor blinks briefly each time it's hit, and the rest of the screen never turns see-through
  • (Optional) Grey meteors show red pips that go down 3, 2, 1 as you hit them

Going Further

  • Make tough meteors fall a little slower than normal ones, so they're fair to shoot three times.
  • Instead of 1 in 4, make tough meteors more common as your score goes up.
  • Try a different hit effect: draw a white rectangle with low alpha over the meteor, or nudge it up a few pixels when hit.

Reference Solution

-- ============================================================
-- Space Shooter — Bonus 6: Tough Meteors
-- Grey meteors take three hits to destroy!
-- ============================================================

local canvas = require("canvas")
canvas.assets.add_path("images")
canvas.set_size(800, 600)

local SCREEN_W = 800
local SCREEN_H = 600

-- ============================================================
-- GAME STATE
-- ============================================================

-- Ship
local ship_x = 370
local ship_y = 500
local ship_w = 60
local ship_h = 48
local ship_speed = 300

-- Lasers
local lasers = {}
local laser_w = 9
local laser_h = 30
local laser_speed = 500

-- Meteors
local meteors = {}
local meteor_w = 48
local meteor_h = 48
local meteor_speed = 150

-- Spawn timer
local spawn_timer = 0
local spawn_interval = 2.0

-- Score
local score = 0

-- Game over
local game_over = false

-- Stars
local stars = {}
local STAR_COUNT = 60

-- Load images
canvas.assets.load_image("ship", "blue_ship.png")
canvas.assets.load_image("laser", "laser.png")
canvas.assets.load_image("meteor", "meteor.png")
canvas.assets.load_image("meteor_grey", "meteor_grey.png")

-- ============================================================
-- GENERATE STAR
-- ============================================================

local function generate_star()
    local size = math.random(1, 3)
    local speed = size * 30
    local brightness = size * 60 + 40
    return {
        x = math.random(0, SCREEN_W),
        y = math.random(0, SCREEN_H),
        size = size,
        speed = speed,
        brightness = brightness
    }
end

-- ============================================================
-- INIT STARS
-- ============================================================

local function init_stars()
    stars = {}
    for i = 1, STAR_COUNT do
        table.insert(stars, generate_star())
    end
end

init_stars()

-- ============================================================
-- COLLISION DETECTION
-- ============================================================

local function check_collision(a_x, a_y, a_w, a_h, b_x, b_y, b_w, b_h)
    return a_x < b_x + b_w
       and a_x + a_w > b_x
       and a_y < b_y + b_h
       and a_y + a_h > b_y
end

-- ============================================================
-- SPAWN METEOR
-- ============================================================

local function spawn_meteor()
    local meteor = {
        x = math.random(0, SCREEN_W - meteor_w),
        y = -meteor_h,
        hp = 1,
        tough = false,
        flash = 0
    }
    -- 1 in 4 meteors is tough
    if math.random(1, 4) == 1 then
        meteor.hp = 3
        meteor.tough = true
    end
    table.insert(meteors, meteor)
end

-- ============================================================
-- SPAWN LASER
-- ============================================================

local function spawn_laser(x, y)
    local laser = {
        x = x,
        y = y
    }
    table.insert(lasers, laser)
end

-- ============================================================
-- RESET GAME
-- ============================================================

local function reset_game()
    ship_x = 370
    ship_y = 500
    lasers = {}
    meteors = {}
    spawn_timer = 0
    score = 0
    game_over = false
    init_stars()
end

-- ============================================================
-- USER INPUT
-- ============================================================

local function user_input()
    local dt = canvas.get_delta()

    -- Restart on ENTER when game is over
    if game_over then
        if canvas.is_key_pressed(canvas.keys.ENTER) then
            reset_game()
        end
        return
    end

    -- Ship movement
    if canvas.is_key_down(canvas.keys.LEFT) then ship_x = ship_x - ship_speed * dt end
    if canvas.is_key_down(canvas.keys.RIGHT) then ship_x = ship_x + ship_speed * dt end
    if canvas.is_key_down(canvas.keys.UP) then ship_y = ship_y - ship_speed * dt end
    if canvas.is_key_down(canvas.keys.DOWN) then ship_y = ship_y + ship_speed * dt end

    -- Fire laser
    if canvas.is_key_pressed(canvas.keys.SPACE) then
        spawn_laser(ship_x + ship_w / 2 - laser_w / 2, ship_y)
    end
end

-- ============================================================
-- UPDATE
-- ============================================================

local function update()
    if game_over then return end

    local dt = canvas.get_delta()

    -- Clamp ship to screen
    ship_x = math.max(0, math.min(SCREEN_W - ship_w, ship_x))
    ship_y = math.max(0, math.min(SCREEN_H - ship_h, ship_y))

    -- Move lasers and remove off-screen ones
    for i = #lasers, 1, -1 do
        lasers[i].y = lasers[i].y - laser_speed * dt
        if lasers[i].y + laser_h < 0 then
            table.remove(lasers, i)
        end
    end

    -- Spawn timer
    spawn_timer = spawn_timer + dt
    if spawn_timer >= spawn_interval then
        spawn_meteor()
        spawn_timer = 0
    end

    -- Move meteors and remove off-screen ones
    for i = #meteors, 1, -1 do
        meteors[i].y = meteors[i].y + meteor_speed * dt
        meteors[i].flash = math.max(0, meteors[i].flash - dt)
        if meteors[i].y > SCREEN_H then
            table.remove(meteors, i)
        end
    end

    -- Laser vs meteor collision
    for i = #lasers, 1, -1 do
        for j = #meteors, 1, -1 do
            local meteor = meteors[j]
            if check_collision(lasers[i].x, lasers[i].y, laser_w, laser_h,
                               meteor.x, meteor.y, meteor_w, meteor_h) then
                -- Every hit uses up the laser and costs the meteor 1 hp
                table.remove(lasers, i)
                meteor.hp = meteor.hp - 1
                meteor.flash = 0.1
                if meteor.hp <= 0 then
                    table.remove(meteors, j)
                    if meteor.tough then
                        score = score + 3
                    else
                        score = score + 1
                    end
                end
                break
            end
        end
    end

    -- Ship vs meteor collision
    for i, meteor in ipairs(meteors) do
        if check_collision(ship_x, ship_y, ship_w, ship_h,
                           meteor.x, meteor.y, meteor_w, meteor_h) then
            game_over = true
            return
        end
    end

    -- Move stars
    for i, star in ipairs(stars) do
        star.y = star.y + star.speed * dt
        if star.y > SCREEN_H then
            star.x = math.random(0, SCREEN_W)
            star.y = -star.size
        end
    end
end

-- ============================================================
-- DRAW
-- ============================================================

local function draw()
    canvas.clear()

    -- Dark space background
    canvas.set_color(10, 10, 30)
    canvas.fill_rect(0, 0, SCREEN_W, SCREEN_H)

    -- Stars
    for i, star in ipairs(stars) do
        canvas.set_color(star.brightness, star.brightness, star.brightness)
        canvas.fill_rect(star.x, star.y, star.size, star.size)
    end

    -- Lasers
    for i, laser in ipairs(lasers) do
        canvas.draw_image("laser", laser.x, laser.y, laser_w, laser_h)
    end

    -- Meteors
    for i, meteor in ipairs(meteors) do
        local image = "meteor"
        if meteor.tough then
            image = "meteor_grey"
        end

        -- Blink (draw see-through) for a moment after being hit
        if meteor.flash > 0 then
            canvas.set_global_alpha(0.3)
        end
        canvas.draw_image(image, meteor.x, meteor.y, meteor_w, meteor_h)
        canvas.set_global_alpha(1)

        -- HP pips above tough meteors
        if meteor.tough then
            canvas.set_color(255, 80, 80)
            for p = 1, meteor.hp do
                canvas.fill_rect(meteor.x + 8 + (p - 1) * 12, meteor.y - 8, 8, 4)
            end
        end
    end

    -- Ship
    canvas.draw_image("ship", ship_x, ship_y, ship_w, ship_h)

    -- HUD
    canvas.set_color(255, 255, 255)
    canvas.set_font_size(16)
    canvas.draw_text(10, 10, "Score: " .. score)
    canvas.draw_text(10, 30, "Arrow keys: Move | SPACE: Shoot")

    -- Game over overlay
    if game_over then
        -- Dark overlay
        canvas.set_color(0, 0, 0, 180)
        canvas.fill_rect(0, 0, SCREEN_W, SCREEN_H)

        -- "GAME OVER" text (red)
        canvas.set_font_size(48)
        canvas.set_color(255, 50, 50)
        local title = "GAME OVER"
        local title_w = canvas.get_text_width(title)
        canvas.draw_text((SCREEN_W - title_w) / 2, SCREEN_H / 2 - 60, title)

        -- Score text (white)
        canvas.set_font_size(24)
        canvas.set_color(255, 255, 255)
        local score_text = "Score: " .. score
        local score_w = canvas.get_text_width(score_text)
        canvas.draw_text((SCREEN_W - score_w) / 2, SCREEN_H / 2, score_text)

        -- Restart prompt (white)
        local restart_text = "Press ENTER to restart"
        local restart_w = canvas.get_text_width(restart_text)
        canvas.draw_text((SCREEN_W - restart_w) / 2, SCREEN_H / 2 + 40, restart_text)
    end
end

-- ============================================================
-- GAME LOOP
-- ============================================================

local function game()
    user_input()
    update()
    draw()
end

canvas.tick(game)
canvas.start()
