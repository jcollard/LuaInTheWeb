SPACE SHOOTER — BONUS CHALLENGES

★★★ STRUCTUREBonus 11: Enemy Ships That Shoot Back

Red enemy ships sway down the screen and fire lasers at you. Hit them twice to take them down.

Before you start
  • Prerequisites: None — start from your finished Part 7 game.
  • New files for this challenge: images/enemy.png, images/enemy_laser.png
  • Make a backup copy of your game.lua first, so you can always go back.
  • Bonus challenges give you less help than the main guide. Work out where each piece of code goes, and use the hints if you get stuck.

New Concepts

  • Patterns you already know, combined: enemies are spawned and moved like meteors, and their shots work like your lasers (only moving down). A lot of this challenge reuses code you've already written, put together in new ways.
  • Each enemy has its own data: an enemy table can hold more than x and y. Each enemy also gets its own health (hp), its own age (t), and its own fire_timer.
  • math.sin(t) gives a number that smoothly swings back and forth between -1 and 1 as t grows. Multiply it by 80 and it swings between -80 and 80. Add that to a starting x and you get a ship that sways left and right.
  • Countdown timers: instead of counting up to an interval, start a timer at a random number of seconds and subtract dt. When it reaches 0, act and pick a new random time. That way every enemy fires on its own schedule.
  • math.random(10, 20) / 10 gives a random decimal between 1.0 and 2.0. math.random with two numbers only gives whole numbers, so pick a whole number from 10 to 20 and divide it by 10.

CHALLENGE Task 2: Spawn enemies on their own timer
Write a spawn_enemy() function that adds a new enemy right above the top of the screen. Besides x and y, each enemy needs a start_x (where it sways around) and a t (how long it has been alive, starting at 0). It also needs hp = 2 and a fire_timer set to a random time between 1.0 and 2.0 seconds. Then, in update(), use enemy_spawn_timer to call it every enemy_spawn_interval seconds.
The enemy will sway up to 80 pixels left and right of start_x. Pick start_x between 80 and SCREEN_W - enemy_w - 80 so it never swings off the edge.
Copy spawn_meteor() and change it. Store the random x in a local start_x first, because you need it twice: for x and for start_x.
math.random with two numbers only gives whole numbers. To get 1.0 to 2.0 with one decimal place, use math.random(10, 20) / 10.
The spawn timer is a copy of the meteor spawn timer in update(), using enemy_spawn_timer, enemy_spawn_interval, and spawn_enemy().
local function spawn_enemy()
    local start_x = math.random(80, SCREEN_W - enemy_w - 80)
    local enemy = {
        x = start_x,
        y = -enemy_h,
        start_x = start_x,
        t = 0,
        hp = 2,
        fire_timer = math.random(10, 20) / 10
    }
    table.insert(enemies, enemy)
end

-- In update()
-- Enemy spawn timer
enemy_spawn_timer = enemy_spawn_timer + dt
if enemy_spawn_timer >= enemy_spawn_interval then
    spawn_enemy()
    enemy_spawn_timer = 0
end
CHALLENGE Task 3: Fly down and sway
In update(), loop over the enemies. Add dt to each enemy's t, move it down by enemy_speed, and set its x to start_x plus math.sin(enemy.t * 2) * 80 so it sways left and right. Remove enemies that fall off the bottom. Then draw every enemy with the "enemy" image in draw(), before the ship.
Use a reverse loop (for i = #enemies, 1, -1) like the meteor loop, because you remove enemies inside it. Writing local enemy = enemies[i] at the top saves a lot of typing.
math.sin(enemy.t * 2) * 80 swings between -80 and 80. The * 2 makes it sway faster; try other numbers.
The x line is enemy.x = enemy.start_x + math.sin(enemy.t * 2) * 80. Draw with canvas.draw_image("enemy", enemy.x, enemy.y, enemy_w, enemy_h).
-- In update()
-- Move enemies and remove off-screen ones
for i = #enemies, 1, -1 do
    local enemy = enemies[i]
    enemy.t = enemy.t + dt
    enemy.y = enemy.y + enemy_speed * dt
    enemy.x = enemy.start_x + math.sin(enemy.t * 2) * 80

    if enemy.y > SCREEN_H then
        table.remove(enemies, i)
    end
end

-- In draw(), before the ship
-- Enemies
for i, enemy in ipairs(enemies) do
    canvas.draw_image("enemy", enemy.x, enemy.y, enemy_w, enemy_h)
end
CHALLENGE Task 4: Fire back
This task has more pieces than the ones before it, so take it one step at a time. Write spawn_enemy_laser(x, y) that adds a laser to enemy_lasers. Inside the enemy loop, count each enemy's fire_timer down. When it reaches 0, fire a laser from the enemy's nose (bottom middle) and pick a new random fire_timer the same way as in Task 2. Then move enemy lasers down, remove the ones that leave the bottom, and draw them with the "enemy_laser" image, before the enemies.
spawn_enemy_laser is a copy of spawn_laser that inserts into enemy_lasers. The enemy laser loop is a copy of your laser loop, but with + instead of - and a check for > SCREEN_H.
Your own lasers start at ship_x + ship_w / 2 - laser_w / 2. An enemy's nose is at enemy.x + enemy_w / 2 - laser_w / 2 across and enemy.y + enemy_h down.
Put the fire code inside the enemy loop, before the off-screen check: subtract dt from enemy.fire_timer, and if enemy.fire_timer <= 0 then fire and reset it with math.random(10, 20) / 10.
local function spawn_enemy_laser(x, y)
    local laser = {
        x = x,
        y = y

    table.insert(enemy_lasers, laser)
end

-- In update(), inside the enemy loop (before the off-screen check)
enemy.fire_timer = enemy.fire_timer - dt
if enemy.fire_timer <= 0 then

end

CHALLENGE Task 5: Shoot them down
After the laser vs meteor check, check your lasers against the enemies. A hit removes the laser and takes 1 off the enemy's hp. When its hp reaches 0, remove the enemy and add 5 to the score.
Start from a copy of the laser vs meteor nested loop. Swap meteors for enemies and use enemy_w and enemy_h.
Don't remove the enemy right away. Subtract from enemies[j].hp first, then only remove it if enemies[j].hp <= 0. Keep the break, because that laser is gone.
-- Laser vs enemy collision
for i = #lasers, 1, -1 do
    for j = #enemies, 1, -1 do
        if check_collision(lasers[i].x, lasers[i].y, laser_w, laser_h,
                           enemies[j].x, enemies[j].y, enemy_w, enemy_h) then
            table.remove(lasers, i)
            enemies[j].hp = enemies[j].hp - 1
            if enemies[j].hp <= 0 then
                table.remove(enemies, j)
                score = score + 5
            end
            break
        end
    end
end

Check Your Work

Run game.lua. You should see:

  • About every 5 seconds a red enemy ship flies in from the top, swaying left and right as it slowly comes down
  • Each enemy fires red lasers straight down, and different enemies fire at different times
  • One hit doesn't destroy an enemy; the second hit does, and your score goes up by 5
  • Touching an enemy or getting hit by a red laser ends the game
  • After pressing ENTER, the screen is clear of enemies and red lasers

-- ============================================================
-- Space Shooter — Bonus 11: Enemy Ships That Shoot Back
-- Red enemy ships sway down the screen and fire lasers at you!
-- ============================================================

local canvas = require("canvas")
canvas.assets.add_path("images")
canvas.set_size(800, 600)

local SCREEN_W = 800
local SCREEN_H = 600

-- ============================================================
-- GAME STATE
-- ============================================================

-- Ship
local ship_x = 370
local ship_y = 500
local ship_w = 60
local ship_h = 48
local ship_speed = 300

-- Lasers
local lasers = {}
local laser_w = 9
local laser_h = 30
local laser_speed = 500

-- Meteors
local meteors = {}
local meteor_w = 48
local meteor_h = 48
local meteor_speed = 150

-- Spawn timer
local spawn_timer = 0
local spawn_interval = 2.0

-- Enemy ships
local enemies = {}
local enemy_w = 60
local enemy_h = 54
local enemy_speed = 60
local enemy_spawn_timer = 0
local enemy_spawn_interval = 5.0

-- Enemy lasers
local enemy_lasers = {}
local enemy_laser_speed = 300

-- Score
local score = 0

-- Game over
local game_over = false

-- Stars
local stars = {}
local STAR_COUNT = 60

-- Load images
canvas.assets.load_image("ship", "blue_ship.png")
canvas.assets.load_image("laser", "laser.png")
canvas.assets.load_image("meteor", "meteor.png")
canvas.assets.load_image("enemy", "enemy.png")
canvas.assets.load_image("enemy_laser", "enemy_laser.png")

-- ============================================================
-- GENERATE STAR
-- ============================================================

local function generate_star()
    local size = math.random(1, 3)
    local speed = size * 30
    local brightness = size * 60 + 40
    return {
        x = math.random(0, SCREEN_W),
        y = math.random(0, SCREEN_H),
        size = size,
        speed = speed,
        brightness = brightness
    }
end

-- ============================================================
-- INIT STARS
-- ============================================================

local function init_stars()
    stars = {}
    for i = 1, STAR_COUNT do
        table.insert(stars, generate_star())
    end
end

init_stars()

-- ============================================================
-- COLLISION DETECTION
-- ============================================================

local function check_collision(a_x, a_y, a_w, a_h, b_x, b_y, b_w, b_h)
    return a_x < b_x + b_w
       and a_x + a_w > b_x
       and a_y < b_y + b_h
       and a_y + a_h > b_y
end

-- ============================================================
-- SPAWN METEOR
-- ============================================================

local function spawn_meteor()
    local meteor = {
        x = math.random(0, SCREEN_W - meteor_w),
        y = -meteor_h
    }
    table.insert(meteors, meteor)
end

-- ============================================================
-- SPAWN LASER
-- ============================================================

local function spawn_laser(x, y)
    local laser = {
        x = x,
        y = y
    }
    table.insert(lasers, laser)
end

-- ============================================================
-- SPAWN ENEMY
-- ============================================================

local function spawn_enemy()
    local start_x = math.random(80, SCREEN_W - enemy_w - 80)
    local enemy = {
        x = start_x,
        y = -enemy_h,
        start_x = start_x,
        t = 0,
        hp = 2,
        fire_timer = math.random(10, 20) / 10
    }
    table.insert(enemies, enemy)
end

-- ============================================================
-- SPAWN ENEMY LASER
-- ============================================================

local function spawn_enemy_laser(x, y)
    local laser = {
        x = x,
        y = y
    }
    table.insert(enemy_lasers, laser)
end

-- ============================================================
-- RESET GAME
-- ============================================================

local function reset_game()
    ship_x = 370
    ship_y = 500
    lasers = {}
    meteors = {}
    spawn_timer = 0
    enemies = {}
    enemy_lasers = {}
    enemy_spawn_timer = 0
    score = 0
    game_over = false
    init_stars()
end

-- ============================================================
-- USER INPUT
-- ============================================================

local function user_input()
    local dt = canvas.get_delta()

    -- Restart on ENTER when game is over
    if game_over then
        if canvas.is_key_pressed(canvas.keys.ENTER) then
            reset_game()
        end
        return
    end

    -- Ship movement
    if canvas.is_key_down(canvas.keys.LEFT) then ship_x = ship_x - ship_speed * dt end
    if canvas.is_key_down(canvas.keys.RIGHT) then ship_x = ship_x + ship_speed * dt end
    if canvas.is_key_down(canvas.keys.UP) then ship_y = ship_y - ship_speed * dt end
    if canvas.is_key_down(canvas.keys.DOWN) then ship_y = ship_y + ship_speed * dt end

    -- Fire laser
    if canvas.is_key_pressed(canvas.keys.SPACE) then
        spawn_laser(ship_x + ship_w / 2 - laser_w / 2, ship_y)
    end
end

-- ============================================================
-- UPDATE
-- ============================================================

local function update()
    if game_over then return end

    local dt = canvas.get_delta()

    -- Clamp ship to screen
    ship_x = math.max(0, math.min(SCREEN_W - ship_w, ship_x))
    ship_y = math.max(0, math.min(SCREEN_H - ship_h, ship_y))

    -- Move lasers and remove off-screen ones
    for i = #lasers, 1, -1 do
        lasers[i].y = lasers[i].y - laser_speed * dt
        if lasers[i].y + laser_h < 0 then
            table.remove(lasers, i)
        end
    end

    -- Spawn timer
    spawn_timer = spawn_timer + dt
    if spawn_timer >= spawn_interval then
        spawn_meteor()
        spawn_timer = 0
    end

    -- Move meteors and remove off-screen ones
    for i = #meteors, 1, -1 do
        meteors[i].y = meteors[i].y + meteor_speed * dt
        if meteors[i].y > SCREEN_H then
            table.remove(meteors, i)
        end
    end

    -- Enemy spawn timer
    enemy_spawn_timer = enemy_spawn_timer + dt
    if enemy_spawn_timer >= enemy_spawn_interval then
        spawn_enemy()
        enemy_spawn_timer = 0
    end

    -- Move enemies, let them fire, and remove off-screen ones
    for i = #enemies, 1, -1 do
        local enemy = enemies[i]
        enemy.t = enemy.t + dt
        enemy.y = enemy.y + enemy_speed * dt
        enemy.x = enemy.start_x + math.sin(enemy.t * 2) * 80

        enemy.fire_timer = enemy.fire_timer - dt
        if enemy.fire_timer <= 0 then
            spawn_enemy_laser(enemy.x + enemy_w / 2 - laser_w / 2, enemy.y + enemy_h)
            enemy.fire_timer = math.random(10, 20) / 10
        end

        if enemy.y > SCREEN_H then
            table.remove(enemies, i)
        end
    end

    -- Move enemy lasers and remove off-screen ones
    for i = #enemy_lasers, 1, -1 do
        enemy_lasers[i].y = enemy_lasers[i].y + enemy_laser_speed * dt
        if enemy_lasers[i].y > SCREEN_H then
            table.remove(enemy_lasers, i)
        end
    end

    -- Laser vs meteor collision
    for i = #lasers, 1, -1 do
        for j = #meteors, 1, -1 do
            if check_collision(lasers[i].x, lasers[i].y, laser_w, laser_h,
                               meteors[j].x, meteors[j].y, meteor_w, meteor_h) then
                table.remove(meteors, j)
                table.remove(lasers, i)
                score = score + 1
                break
            end
        end
    end

    -- Laser vs enemy collision
    for i = #lasers, 1, -1 do
        for j = #enemies, 1, -1 do
            if check_collision(lasers[i].x, lasers[i].y, laser_w, laser_h,
                               enemies[j].x, enemies[j].y, enemy_w, enemy_h) then
                table.remove(lasers, i)
                enemies[j].hp = enemies[j].hp - 1
                if enemies[j].hp <= 0 then
                    table.remove(enemies, j)
                    score = score + 5
                end
                break
            end
        end
    end

    -- Ship vs meteor collision
    for i, meteor in ipairs(meteors) do
        if check_collision(ship_x, ship_y, ship_w, ship_h,
                           meteor.x, meteor.y, meteor_w, meteor_h) then
            game_over = true
            return
        end
    end

    -- Ship vs enemy collision
    for i, enemy in ipairs(enemies) do
        if check_collision(ship_x, ship_y, ship_w, ship_h,
                           enemy.x, enemy.y, enemy_w, enemy_h) then
            game_over = true
            return
        end
    end

    -- Ship vs enemy laser collision
    for i, laser in ipairs(enemy_lasers) do
        if check_collision(ship_x, ship_y, ship_w, ship_h,
                           laser.x, laser.y, laser_w, laser_h) then
            game_over = true
            return
        end
    end

    -- Move stars
    for i, star in ipairs(stars) do
        star.y = star.y + star.speed * dt
        if star.y > SCREEN_H then
            star.x = math.random(0, SCREEN_W)
            star.y = -star.size
        end
    end
end

-- ============================================================
-- DRAW
-- ============================================================

local function draw()
    canvas.clear()

    -- Dark space background
    canvas.set_color(10, 10, 30)
    canvas.fill_rect(0, 0, SCREEN_W, SCREEN_H)

    -- Stars
    for i, star in ipairs(stars) do
        canvas.set_color(star.brightness, star.brightness, star.brightness)
        canvas.fill_rect(star.x, star.y, star.size, star.size)
    end

    -- Lasers
    for i, laser in ipairs(lasers) do
        canvas.draw_image("laser", laser.x, laser.y, laser_w, laser_h)
    end

    -- Meteors
    for i, meteor in ipairs(meteors) do
        canvas.draw_image("meteor", meteor.x, meteor.y, meteor_w, meteor_h)
    end

    -- Enemy lasers
    for i, laser in ipairs(enemy_lasers) do
        canvas.draw_image("enemy_laser", laser.x, laser.y, laser_w, laser_h)
    end

    -- Enemies
    for i, enemy in ipairs(enemies) do
        canvas.draw_image("enemy", enemy.x, enemy.y, enemy_w, enemy_h)
    end

    -- Ship
    canvas.draw_image("ship", ship_x, ship_y, ship_w, ship_h)

    -- HUD
    canvas.set_color(255, 255, 255)
    canvas.set_font_size(16)
    canvas.draw_text(10, 10, "Score: " .. score)
    canvas.draw_text(10, 30, "Arrow keys: Move | SPACE: Shoot")

    -- Game over overlay
    if game_over then
        -- Dark overlay
        canvas.set_color(0, 0, 0, 180)
        canvas.fill_rect(0, 0, SCREEN_W, SCREEN_H)

        -- "GAME OVER" text (red)
        canvas.set_font_size(48)
        canvas.set_color(255, 50, 50)
        local title = "GAME OVER"
        local title_w = canvas.get_text_width(title)
        canvas.draw_text((SCREEN_W - title_w) / 2, SCREEN_H / 2 - 60, title)

        -- Score text (white)
        canvas.set_font_size(24)
        canvas.set_color(255, 255, 255)
        local score_text = "Score: " .. score
        local score_w = canvas.get_text_width(score_text)
        canvas.draw_text((SCREEN_W - score_w) / 2, SCREEN_H / 2, score_text)

        -- Restart prompt (white)
        local restart_text = "Press ENTER to restart"
        local restart_w = canvas.get_text_width(restart_text)
        canvas.draw_text((SCREEN_W - restart_w) / 2, SCREEN_H / 2 + 40, restart_text)
    end
end

-- ============================================================
-- GAME LOOP
-- ============================================================

local function game()
    user_input()
    update()
    draw()
end

canvas.tick(game)
canvas.start()
