SPACE SHOOTER — BONUS CHALLENGES

★★★ STRUCTUREBonus 14: Mouse & Gamepad Controls

Fly the ship with the mouse or a gamepad, while the keyboard keeps working too.

Before you start
  • Prerequisites: None — start from your finished Part 7 game.
  • Make a backup copy of your game.lua first, so you can always go back.
  • Bonus challenges give you less help than the main guide. Work out where each piece of code goes, and use the hints if you get stuck.

New Concepts

  • Input is numbers: the ship doesn't care what moved it. Keyboard, mouse, and gamepad code can all change the same ship_x and ship_y. The clamping in update() keeps the ship on screen no matter which device moved it.
  • Mouse: canvas.get_mouse_x() and canvas.get_mouse_y() give the pointer's position. canvas.is_mouse_down(0) is true while the left button is held; canvas.is_mouse_pressed(0) is true only on the frame it was clicked. (0 means the left button.)
  • Gamepad: canvas.is_gamepad_connected(1) checks for gamepad number 1. canvas.get_gamepad_axis(1, canvas.axes.LEFT_STICK_X) gives a number from -1 (full left) to 1 (full right). LEFT_STICK_Y is -1 for up and 1 for down, the same direction as screen y. canvas.is_gamepad_button_pressed(1, canvas.buttons.SOUTH) works like is_key_pressed. SOUTH is the bottom face button: A on Xbox, ✕ on PlayStation.
  • Dead zone: a real stick never rests at exactly 0. It might sit at 0.03 or -0.07, which would make your ship slowly drift. Ignoring small values (under 0.2) fixes that.
  • math.abs(x) gives the size of a number without its sign. math.abs(-0.5) is 0.5.
CHALLENGE Task 1: Fly toward the mouse
While the left mouse button is held down, move the ship so its center heads toward the mouse pointer. It should glide there at ship_speed, not jump there instantly. Write a helper function move_toward(current, target, max_step) that returns current moved toward target by at most max_step, and use it for both ship_x and ship_y. Save the position the ship is heading for in target_x and target_y. Put move_toward above user_input(), and the mouse code after the arrow-key movement. If your ship jumps straight to the pointer, check that each move goes through the helper function instead of setting the position to the target.
If you did Bonus 8: Power-Ups, use the same speed your arrow keys use (your speed variable) here and in Task 2, instead of ship_speed. Then the speed boost works with every device.
The button has to be held because the mouse is always somewhere. If the ship always chased it, the mouse would fight the keyboard. Press LEFT and the ship would get pulled straight back to the pointer. Holding the button says “I'm using the mouse now.” Gliding matters too. With the speed limit, the mouse is exactly as fast as the keyboard, so it isn't a cheat. A ship that can teleport could dodge anything!
In move_toward: if current is less than target, add max_step; otherwise subtract it. But don't overshoot, or the ship will wobble back and forth around the pointer. math.min(current + max_step, target) picks the smaller of the two numbers, so it stops at the target.
The ship's position is its top-left corner. To put its center on the pointer, the target is canvas.get_mouse_x() - ship_w / 2 (and the same for y with ship_h).
Put move_toward above user_input(). Then, after the arrow-key movement, add if canvas.is_mouse_down(0) then ... end and inside it call ship_x = move_toward(ship_x, target_x, ship_speed * dt), and the same for ship_y.
-- Move current toward target, but never by more than max_step
local function move_toward(current, target, max_step)
    if current < target then
        return math.min(current + max_step, target)
    else
        return math.max(current - max_step, target)
    end
end

-- In user_input(), after the arrow-key movement
-- Mouse: hold the left button to fly toward the pointer
if canvas.is_mouse_down(0) then
    local target_x = canvas.get_mouse_x() - ship_w / 2
    local target_y = canvas.get_mouse_y() - ship_h / 2
    ship_x = move_toward(ship_x, target_x, ship_speed * dt)
    ship_y = move_toward(ship_y, target_y, ship_speed * dt)
end
CHALLENGE Task 2: Gamepad stick
At the top of user_input(), store whether gamepad 1 is connected in a variable has_pad. If it is, read the left stick into stick_x and stick_y, and move the ship by the stick value times ship_speed * dt. Add a DEAD_ZONE constant of 0.2 next to ship_speed, and ignore any stick value smaller than that (in either direction). Put the stick code after the mouse movement.
Multiplying by the stick value gives you something the keyboard can't: analog control. Push the stick halfway and the ship flies at half speed.
Compare to the arrow keys: ship_x = ship_x + ship_speed * dt. For the stick, multiply by stick_x as well. A negative value moves left on its own, so you don't need a separate LEFT check.
The stick can be pushed left (negative) or right (positive). math.abs(stick_x) > DEAD_ZONE checks both directions at once.
Inside if has_pad then ... end, read stick_x with canvas.get_gamepad_axis(1, canvas.axes.LEFT_STICK_X) and stick_y with LEFT_STICK_Y. Then one if line for each, the same way as the arrow keys.
-- In GAME STATE, after ship_speed
-- Gamepad stick values smaller than this are ignored
local DEAD_ZONE = 0.2

-- At the top of user_input()
local dt = canvas.get_delta()
local has_pad = canvas.is_gamepad_connected(1)

-- In user_input(), after the mouse movement
-- Gamepad: left stick moves the ship
if has_pad then
    local stick_x = canvas.get_gamepad_axis(1, canvas.axes.LEFT_STICK_X)
    local stick_y = canvas.get_gamepad_axis(1, canvas.axes.LEFT_STICK_Y)
    if math.abs(stick_x) > DEAD_ZONE then ship_x = ship_x + stick_x * ship_speed * dt end
    if math.abs(stick_y) > DEAD_ZONE then ship_y = ship_y + stick_y * ship_speed * dt end
end
CHALLENGE Task 3: Fire from any device
Make the ship fire when SPACE is pressed, or the left mouse button is clicked, or the gamepad's SOUTH button is pressed. Replace your SPACE check with a fire variable, and put your firing code inside one if fire then ... end block, so every device fires the same way.
Other bonus challenges may have changed what firing does, such as triple shot from Bonus 8: Power-Ups or the laser sound from Bonus 13: Sound Effects. Keep all of that code inside the if fire then block. Only the check at the top changes.
Make a variable fire that is true if any device asked to shoot. Then move your firing code inside if fire then ... end.
You can join checks with or: local fire = canvas.is_key_pressed(canvas.keys.SPACE) or canvas.is_mouse_pressed(0). Use is_mouse_pressed, not is_mouse_down, or holding the button would fire every frame.
Only ask about the gamepad button if there is a gamepad: if has_pad and canvas.is_gamepad_button_pressed(1, canvas.buttons.SOUTH) then fire = true end.
-- Fire laser: SPACE, left click, or the gamepad's bottom button
local fire = canvas.is_key_pressed(canvas.keys.SPACE) or canvas.is_mouse_pressed(0)
if has_pad and canvas.is_gamepad_button_pressed(1, canvas.buttons.SOUTH) then
    fire = true
end
if fire then
    spawn_laser(ship_x + ship_w / 2 - laser_w / 2, ship_y)
end
CHALLENGE Task 4: START to restart, and update the text
On the game over screen, pressing START on the gamepad should restart the game, the same way ENTER does. If you did Bonus 10: Game States, add it to the ENTER checks on both the title screen and the game over screen. Otherwise a player with only a gamepad gets stuck on the title screen. Change the restart prompt to "Press ENTER or START to restart", and update the controls line in the HUD to mention the new controls, so a player holding a gamepad knows what to press. Keep any controls other bonus challenges added.
Add an or to the ENTER check inside if game_over then. Use canvas.buttons.START.
Wrap the gamepad part in parentheses so it's easier to read: or (has_pad and canvas.is_gamepad_button_pressed(1, canvas.buttons.START)). Setting has_pad at the very top of user_input(), before the game over check, is what lets this work.
-- Restart on ENTER (or START on a gamepad) when game is over
if game_over then
    if canvas.is_key_pressed(canvas.keys.ENTER)
       or (has_pad and canvas.is_gamepad_button_pressed(1, canvas.buttons.START)) then
        reset_game()
    end
    return
end

-- In draw(), HUD section
canvas.draw_text(10, 30, "Move: Arrows / Stick / Hold mouse | Shoot: SPACE / A / Click")

-- In draw(), game over overlay
local restart_text = "Press ENTER or START to restart"

Check Your Work

Run game.lua. You should see:

  • The arrow keys and SPACE still work exactly like before
  • Holding the left mouse button makes the ship glide toward the pointer and stop with its center on it
  • Letting go of the mouse button leaves the ship where it is, and the arrow keys take over
  • Every mouse click fires a laser
  • With a gamepad plugged in, the left stick moves the ship. (Press a button on it first so the browser notices it.) A little push is slow, a full push is fast, and letting go stops the ship with no drifting
  • The A / ✕ button fires, and START restarts after a game over

Going Further

  • Let the gamepad's D-pad move the ship too. Use canvas.get_gamepad_button(1, canvas.buttons.DPAD_LEFT), which is 1 while held and 0 when not.
  • Hold UP and RIGHT together and the ship flies about 1.4 times faster than with one key. The stick doesn't have this problem, because a stick pushed diagonally only reads about 0.7 on each axis. Try fixing the keyboard so diagonal moves are the same speed.
  • Try a different mouse style: the ship follows the pointer all the time, but only after the mouse has moved. (Hint: remember last frame's mouse position and compare.) Which feels better?

Reference Solution

Read this first: this is one complete version of game.lua with this challenge finished, built from the Part 7 code. Your game is probably different — you may have changed numbers, names, or added other bonus features — so copying it over your file will likely not work and could erase your own work. Use it to compare ideas, then make the changes in your version.
-- ============================================================
-- Space Shooter — Bonus 14: Mouse & Gamepad Controls
-- Fly with the keyboard, the mouse, or a gamepad: input is just numbers!
-- ============================================================

local canvas = require("canvas")
canvas.assets.add_path("images")
canvas.set_size(800, 600)

local SCREEN_W = 800
local SCREEN_H = 600

-- ============================================================
-- GAME STATE
-- ============================================================

-- Ship
local ship_x = 370
local ship_y = 500
local ship_w = 60
local ship_h = 48
local ship_speed = 300

-- Gamepad stick values smaller than this are ignored
local DEAD_ZONE = 0.2

-- Lasers
local lasers = {}
local laser_w = 9
local laser_h = 30
local laser_speed = 500

-- Meteors
local meteors = {}
local meteor_w = 48
local meteor_h = 48
local meteor_speed = 150

-- Spawn timer
local spawn_timer = 0
local spawn_interval = 2.0

-- Score
local score = 0

-- Game over
local game_over = false

-- Stars
local stars = {}
local STAR_COUNT = 60

-- Load images
canvas.assets.load_image("ship", "blue_ship.png")
canvas.assets.load_image("laser", "laser.png")
canvas.assets.load_image("meteor", "meteor.png")

-- ============================================================
-- GENERATE STAR
-- ============================================================

local function generate_star()
    local size = math.random(1, 3)
    local speed = size * 30
    local brightness = size * 60 + 40
    return {
        x = math.random(0, SCREEN_W),
        y = math.random(0, SCREEN_H),
        size = size,
        speed = speed,
        brightness = brightness
    }
end

-- ============================================================
-- INIT STARS
-- ============================================================

local function init_stars()
    stars = {}
    for i = 1, STAR_COUNT do
        table.insert(stars, generate_star())
    end
end

init_stars()

-- ============================================================
-- COLLISION DETECTION
-- ============================================================

local function check_collision(a_x, a_y, a_w, a_h, b_x, b_y, b_w, b_h)
    return a_x < b_x + b_w
       and a_x + a_w > b_x
       and a_y < b_y + b_h
       and a_y + a_h > b_y
end

-- ============================================================
-- SPAWN METEOR
-- ============================================================

local function spawn_meteor()
    local meteor = {
        x = math.random(0, SCREEN_W - meteor_w),
        y = -meteor_h
    }
    table.insert(meteors, meteor)
end

-- ============================================================
-- SPAWN LASER
-- ============================================================

local function spawn_laser(x, y)
    local laser = {
        x = x,
        y = y
    }
    table.insert(lasers, laser)
end

-- ============================================================
-- MOVE TOWARD
-- ============================================================

-- Move current toward target, but never by more than max_step
local function move_toward(current, target, max_step)
    if current < target then
        return math.min(current + max_step, target)
    else
        return math.max(current - max_step, target)
    end
end

-- ============================================================
-- RESET GAME
-- ============================================================

local function reset_game()
    ship_x = 370
    ship_y = 500
    lasers = {}
    meteors = {}
    spawn_timer = 0
    score = 0
    game_over = false
    init_stars()
end

-- ============================================================
-- USER INPUT
-- ============================================================

local function user_input()
    local dt = canvas.get_delta()
    local has_pad = canvas.is_gamepad_connected(1)

    -- Restart on ENTER (or START on a gamepad) when game is over
    if game_over then
        if canvas.is_key_pressed(canvas.keys.ENTER)
           or (has_pad and canvas.is_gamepad_button_pressed(1, canvas.buttons.START)) then
            reset_game()
        end
        return
    end

    -- Ship movement
    if canvas.is_key_down(canvas.keys.LEFT) then ship_x = ship_x - ship_speed * dt end
    if canvas.is_key_down(canvas.keys.RIGHT) then ship_x = ship_x + ship_speed * dt end
    if canvas.is_key_down(canvas.keys.UP) then ship_y = ship_y - ship_speed * dt end
    if canvas.is_key_down(canvas.keys.DOWN) then ship_y = ship_y + ship_speed * dt end

    -- Mouse: hold the left button to fly toward the pointer
    if canvas.is_mouse_down(0) then
        local target_x = canvas.get_mouse_x() - ship_w / 2
        local target_y = canvas.get_mouse_y() - ship_h / 2
        ship_x = move_toward(ship_x, target_x, ship_speed * dt)
        ship_y = move_toward(ship_y, target_y, ship_speed * dt)
    end

    -- Gamepad: left stick moves the ship
    if has_pad then
        local stick_x = canvas.get_gamepad_axis(1, canvas.axes.LEFT_STICK_X)
        local stick_y = canvas.get_gamepad_axis(1, canvas.axes.LEFT_STICK_Y)
        if math.abs(stick_x) > DEAD_ZONE then ship_x = ship_x + stick_x * ship_speed * dt end
        if math.abs(stick_y) > DEAD_ZONE then ship_y = ship_y + stick_y * ship_speed * dt end
    end

    -- Fire laser: SPACE, left click, or the gamepad's bottom button
    local fire = canvas.is_key_pressed(canvas.keys.SPACE) or canvas.is_mouse_pressed(0)
    if has_pad and canvas.is_gamepad_button_pressed(1, canvas.buttons.SOUTH) then
        fire = true
    end
    if fire then
        spawn_laser(ship_x + ship_w / 2 - laser_w / 2, ship_y)
    end
end

-- ============================================================
-- UPDATE
-- ============================================================

local function update()
    if game_over then return end

    local dt = canvas.get_delta()

    -- Clamp ship to screen
    ship_x = math.max(0, math.min(SCREEN_W - ship_w, ship_x))
    ship_y = math.max(0, math.min(SCREEN_H - ship_h, ship_y))

    -- Move lasers and remove off-screen ones
    for i = #lasers, 1, -1 do
        lasers[i].y = lasers[i].y - laser_speed * dt
        if lasers[i].y + laser_h < 0 then
            table.remove(lasers, i)
        end
    end

    -- Spawn timer
    spawn_timer = spawn_timer + dt
    if spawn_timer >= spawn_interval then
        spawn_meteor()
        spawn_timer = 0
    end

    -- Move meteors and remove off-screen ones
    for i = #meteors, 1, -1 do
        meteors[i].y = meteors[i].y + meteor_speed * dt
        if meteors[i].y > SCREEN_H then
            table.remove(meteors, i)
        end
    end

    -- Laser vs meteor collision
    for i = #lasers, 1, -1 do
        for j = #meteors, 1, -1 do
            if check_collision(lasers[i].x, lasers[i].y, laser_w, laser_h,
                               meteors[j].x, meteors[j].y, meteor_w, meteor_h) then
                table.remove(meteors, j)
                table.remove(lasers, i)
                score = score + 1
                break
            end
        end
    end

    -- Ship vs meteor collision
    for i, meteor in ipairs(meteors) do
        if check_collision(ship_x, ship_y, ship_w, ship_h,
                           meteor.x, meteor.y, meteor_w, meteor_h) then
            game_over = true
            return
        end
    end

    -- Move stars
    for i, star in ipairs(stars) do
        star.y = star.y + star.speed * dt
        if star.y > SCREEN_H then
            star.x = math.random(0, SCREEN_W)
            star.y = -star.size
        end
    end
end

-- ============================================================
-- DRAW
-- ============================================================

local function draw()
    canvas.clear()

    -- Dark space background
    canvas.set_color(10, 10, 30)
    canvas.fill_rect(0, 0, SCREEN_W, SCREEN_H)

    -- Stars
    for i, star in ipairs(stars) do
        canvas.set_color(star.brightness, star.brightness, star.brightness)
        canvas.fill_rect(star.x, star.y, star.size, star.size)
    end

    -- Lasers
    for i, laser in ipairs(lasers) do
        canvas.draw_image("laser", laser.x, laser.y, laser_w, laser_h)
    end

    -- Meteors
    for i, meteor in ipairs(meteors) do
        canvas.draw_image("meteor", meteor.x, meteor.y, meteor_w, meteor_h)
    end

    -- Ship
    canvas.draw_image("ship", ship_x, ship_y, ship_w, ship_h)

    -- HUD
    canvas.set_color(255, 255, 255)
    canvas.set_font_size(16)
    canvas.draw_text(10, 10, "Score: " .. score)
    canvas.draw_text(10, 30, "Move: Arrows / Stick / Hold mouse | Shoot: SPACE / A / Click")

    -- Game over overlay
    if game_over then
        -- Dark overlay
        canvas.set_color(0, 0, 0, 180)
        canvas.fill_rect(0, 0, SCREEN_W, SCREEN_H)

        -- "GAME OVER" text (red)
        canvas.set_font_size(48)
        canvas.set_color(255, 50, 50)
        local title = "GAME OVER"
        local title_w = canvas.get_text_width(title)
        canvas.draw_text((SCREEN_W - title_w) / 2, SCREEN_H / 2 - 60, title)

        -- Score text (white)
        canvas.set_font_size(24)
        canvas.set_color(255, 255, 255)
        local score_text = "Score: " .. score
        local score_w = canvas.get_text_width(score_text)
        canvas.draw_text((SCREEN_W - score_w) / 2, SCREEN_H / 2, score_text)

        -- Restart prompt (white)
        local restart_text = "Press ENTER or START to restart"
        local restart_w = canvas.get_text_width(restart_text)
        canvas.draw_text((SCREEN_W - restart_w) / 2, SCREEN_H / 2 + 40, restart_text)
    end
end

-- ============================================================
-- GAME LOOP
-- ============================================================

local function game()
    user_input()
    update()
    draw()
end

canvas.tick(game)
canvas.start()
