SPACE SHOOTER — BONUS CHALLENGES

★★★ STRUCTUREBonus 12: Waves & a Boss

Swap endless spawning for numbered waves, and fight a big boss with a health bar every third wave.

Before you start
  • Prerequisites: Finish 11_enemy_ships.html (Enemy Ships That Shoot Back) first.
  • New files for this challenge: images/boss.png
  • Make a backup copy of your game.lua first, so you can always go back.
  • Bonus challenges give you less help than the main guide. Work out where each piece of code goes, and use the hints if you get stuck.

New Concepts

  • A state variable: wave_state holds a string, either "banner" (showing "WAVE 2") or "fighting". Your code checks it to decide what to do this frame.
  • Counting down what's left: each wave starts with a fixed number of meteors and enemies to spawn. Every spawn subtracts 1. When nothing is left to spawn and nothing is left on screen, the wave is over.
  • nil as "nothing here": there's only ever one boss, so instead of a list, boss is either a table or nil. Always check if boss ~= nil then before you touch boss.x.
  • % (remainder): wave % 3 is what's left over after dividing by 3. It's 0 on waves 3, 6, 9... so if wave % 3 == 0 means "every third wave".
  • Sideways velocity: a laser with vx = 150 moves 150 pixels right per second while it also falls. Three lasers with vx of -150, 0, and 150 make a spread.

It goes up one wave, sets wave_state to "banner", sets banner_timer to BANNER_TIME, and resets both spawn timers. It also sets the wave to have 3 + wave * 2 meteors and wave enemies. Call it once at startup, and make reset_game() set wave back to 0 and call it.
reset_game() calls start_wave(), so write start_wave() above reset_game(). Call start_wave() right after the function, the same way init_stars() is called after its function.
Wave 1 gets 5 meteors and 1 enemy. Wave 2 gets 7 meteors and 2 enemies. Each wave adds 2 more meteors and 1 more enemy.
The variables are wave, wave_state = "banner", banner_timer = 0, BANNER_TIME = 2.0, wave_meteors_left = 0, and wave_enemies_left = 0.

CHALLENGE Task 5: The boss arrives
This is the biggest task in this challenge, so take it one piece at a time. Load boss.png as "boss". Add a boss variable that starts as nil, plus its size, boss_w (200) by boss_h (160), and its side speed, boss_speed (120). Also add the BOSS_Y it stops at (60), BOSS_HP (30), and BOSS_FIRE_INTERVAL (1.2). Write spawn_boss() to make a boss centered above the screen. Besides x, y, and vx, it needs hp and max_hp (both start at BOSS_HP) and a fire_timer that starts at BOSS_FIRE_INTERVAL. In start_wave(), every third wave spawns the boss and no meteors or enemies. In update(), after the enemy loop, move the boss down at 80 pixels per second until it reaches BOSS_Y. Then slide it left and right, turning around at the edges. Draw it, and add and boss == nil to your next-wave check.
spawn_boss() must be written above start_wave(), because start_wave() calls it. Also set boss = nil in reset_game() before calling start_wave(), so a boss from the last game doesn't carry over.
The boss table needs x, y, vx (its side speed, which switches between positive and negative to turn around), hp, max_hp, and a fire_timer for the next task. Start y at -boss_h so it flies in from above.
In start_wave(), wrap the two "left" lines in if wave % 3 == 0 then ... else ... end. The boss branch sets both counts to 0 and calls spawn_boss().
To turn around: if boss.x < 0 then put it back at 0 and set boss.vx = boss_speed. elseif boss.x + boss_w > SCREEN_W then put it back at the right edge and set boss.vx = -boss_speed.

local boss = nil

local function spawn_boss()
    boss = {
        x = (SCREEN_W - boss_w) / 2,
        y = -boss_h,
        vx = boss_speed,
        hp = BOSS_HP,
        max_hp = BOSS_HP,
        fire_timer = BOSS_FIRE_INTERVAL
    }
end

        wave_enemies_left = 0

CHALLENGE Task 7: Fight the boss
This task has four parts, so take them one at a time. Before the next-wave check, make your lasers hit the boss: each hit removes the laser and takes 1 off boss.hp. When hp reaches 0, set boss to nil and add 50 to the score. Touching the boss ends the game. Put that ship vs boss check right before the stars move. Finally, draw a health bar at the top of the screen so you can see how the fight is going. Start with a dark gray background bar, centered across the screen at y = 15. Make it 300 pixels wide and 14 pixels tall, and store the width in a local variable called bar_w. Then draw a red bar on top whose width shrinks as the boss loses health. In the banner, show "BOSS WAVE!" instead of the wave number when there is a boss.
If you get an error about a nil value near the boss code, look for a line that uses boss.x, boss.y, or boss.hp outside an if boss ~= nil then check. That error means the boss was already gone.
There's only one boss, so you only need one loop, over the lasers. Wrap everything in if boss ~= nil then. Check boss.hp <= 0 after the loop.
boss.hp / boss.max_hp is how much health is left, from 1 (full) down to 0. Multiply it by bar_w to get the red bar's width.
Center the bar with bar_x = (SCREEN_W - bar_w) / 2. Draw the gray one with fill_rect(bar_x, 15, bar_w, 14), then the red one at the same spot with width bar_w * boss.hp / boss.max_hp. Put the ship vs boss check right before the stars move.

        if check_collision(lasers[i].x, lasers[i].y, laser_w, laser_h,

local function generate_star()
    local size = math.random(1, 3)
    local speed = size * 30
    local brightness = size * 60 + 40
    return {
        x = math.random(0, SCREEN_W),
        y = math.random(0, SCREEN_H),
        size = size,
        speed = speed,
        brightness = brightness

local function check_collision(a_x, a_y, a_w, a_h, b_x, b_y, b_w, b_h)
    return a_x < b_x + b_w
       and a_x + a_w > b_x
       and a_y < b_y + b_h
       and a_y + a_h > b_y

-- ============================================================
-- USER INPUT
-- ============================================================

local function user_input()
    local dt = canvas.get_delta()

    -- Restart on ENTER when game is over
    if game_over then
        if canvas.is_key_pressed(canvas.keys.ENTER) then
            reset_game()
        end
        return
    end

    -- Ship movement
    if canvas.is_key_down(canvas.keys.LEFT) then ship_x = ship_x - ship_speed * dt end
    if canvas.is_key_down(canvas.keys.RIGHT) then ship_x = ship_x + ship_speed * dt end
    if canvas.is_key_down(canvas.keys.UP) then ship_y = ship_y - ship_speed * dt end
    if canvas.is_key_down(canvas.keys.DOWN) then ship_y = ship_y + ship_speed * dt end

    -- Fire laser
    if canvas.is_key_pressed(canvas.keys.SPACE) then
        spawn_laser(ship_x + ship_w / 2 - laser_w / 2, ship_y)
    end
end

-- ============================================================
-- UPDATE
-- ============================================================

local function update()
    if game_over then return end

    local dt = canvas.get_delta()

    -- Clamp ship to screen
    ship_x = math.max(0, math.min(SCREEN_W - ship_w, ship_x))
    ship_y = math.max(0, math.min(SCREEN_H - ship_h, ship_y))

    -- Move lasers and remove off-screen ones
    for i = #lasers, 1, -1 do
        lasers[i].y = lasers[i].y - laser_speed * dt
        if lasers[i].y + laser_h < 0 then
            table.remove(lasers, i)
        end
    end

    -- Wave banner: count down, then start fighting
    if wave_state == "banner" then
        banner_timer = banner_timer - dt
        if banner_timer <= 0 then
            wave_state = "fighting"
        end
    end

    -- Spawn meteors and enemies only while fighting, until the wave runs out
    if wave_state == "fighting" then
        spawn_timer = spawn_timer + dt
        if spawn_timer >= spawn_interval and wave_meteors_left > 0 then
            spawn_meteor()
            wave_meteors_left = wave_meteors_left - 1
            spawn_timer = 0
        end

        enemy_spawn_timer = enemy_spawn_timer + dt
        if enemy_spawn_timer >= enemy_spawn_interval and wave_enemies_left > 0 then
            spawn_enemy()
            wave_enemies_left = wave_enemies_left - 1
            enemy_spawn_timer = 0
        end
    end

    -- Move meteors and remove off-screen ones
    for i = #meteors, 1, -1 do
        meteors[i].y = meteors[i].y + meteor_speed * dt
        if meteors[i].y > SCREEN_H then
            table.remove(meteors, i)
        end
    end

    -- Move enemies, let them fire, and remove off-screen ones
    for i = #enemies, 1, -1 do
        local enemy = enemies[i]
        enemy.t = enemy.t + dt
        enemy.y = enemy.y + enemy_speed * dt
        enemy.x = enemy.start_x + math.sin(enemy.t * 2) * 80

        enemy.fire_timer = enemy.fire_timer - dt
        if enemy.fire_timer <= 0 then
            spawn_enemy_laser(enemy.x + enemy_w / 2 - laser_w / 2, enemy.y + enemy_h, 0)
            enemy.fire_timer = math.random(10, 20) / 10
        end

        if enemy.y > SCREEN_H then
            table.remove(enemies, i)
        end
    end

    -- Move the boss: fly in from the top, then slide side to side and fire
    if boss ~= nil then
        if boss.y < BOSS_Y then
            boss.y = boss.y + 80 * dt
        else
            boss.x = boss.x + boss.vx * dt
            if boss.x < 0 then
                boss.x = 0
                boss.vx = boss_speed
            elseif boss.x + boss_w > SCREEN_W then
                boss.x = SCREEN_W - boss_w
                boss.vx = -boss_speed
            end

            boss.fire_timer = boss.fire_timer - dt
            if boss.fire_timer <= 0 then
                local gun_x = boss.x + boss_w / 2 - laser_w / 2
                local gun_y = boss.y + boss_h - 20
                spawn_enemy_laser(gun_x, gun_y, -150)
                spawn_enemy_laser(gun_x, gun_y, 0)
                spawn_enemy_laser(gun_x, gun_y, 150)
                boss.fire_timer = BOSS_FIRE_INTERVAL
            end
        end
    end

    -- Move enemy lasers and remove off-screen ones
    for i = #enemy_lasers, 1, -1 do
        enemy_lasers[i].x = enemy_lasers[i].x + enemy_lasers[i].vx * dt
        enemy_lasers[i].y = enemy_lasers[i].y + enemy_laser_speed * dt
        if enemy_lasers[i].y > SCREEN_H then
            table.remove(enemy_lasers, i)
        end
    end

    -- Laser vs meteor collision
    for i = #lasers, 1, -1 do
        for j = #meteors, 1, -1 do
            if check_collision(lasers[i].x, lasers[i].y, laser_w, laser_h,
                               meteors[j].x, meteors[j].y, meteor_w, meteor_h) then
                table.remove(meteors, j)
                table.remove(lasers, i)
                score = score + 1
                break
            end
        end
    end

    -- Laser vs enemy collision
    for i = #lasers, 1, -1 do
        for j = #enemies, 1, -1 do
            if check_collision(lasers[i].x, lasers[i].y, laser_w, laser_h,
                               enemies[j].x, enemies[j].y, enemy_w, enemy_h) then
                table.remove(lasers, i)
                enemies[j].hp = enemies[j].hp - 1
                if enemies[j].hp <= 0 then
                    table.remove(enemies, j)
                    score = score + 5
                end
                break
            end
        end
    end

    -- Laser vs boss collision
    if boss ~= nil then
        for i = #lasers, 1, -1 do
            if check_collision(lasers[i].x, lasers[i].y, laser_w, laser_h,
                               boss.x, boss.y, boss_w, boss_h) then
                table.remove(lasers, i)
                boss.hp = boss.hp - 1
            end
        end
        if boss.hp <= 0 then
            boss = nil
            score = score + 50
        end
    end

    -- Next wave when everything is spawned and cleared
    if wave_state == "fighting"
       and wave_meteors_left == 0 and wave_enemies_left == 0
       and #meteors == 0 and #enemies == 0 and boss == nil then
        start_wave()
    end

    -- Ship vs meteor collision
    for i, meteor in ipairs(meteors) do
        if check_collision(ship_x, ship_y, ship_w, ship_h,
                           meteor.x, meteor.y, meteor_w, meteor_h) then
            game_over = true
            return
        end
    end

    -- Ship vs enemy collision
    for i, enemy in ipairs(enemies) do
        if check_collision(ship_x, ship_y, ship_w, ship_h,
                           enemy.x, enemy.y, enemy_w, enemy_h) then
            game_over = true
            return
        end
    end

    -- Ship vs enemy laser collision
    for i, laser in ipairs(enemy_lasers) do
        if check_collision(ship_x, ship_y, ship_w, ship_h,
                           laser.x, laser.y, laser_w, laser_h) then
            game_over = true
            return
        end
    end

    -- Ship vs boss collision
    if boss ~= nil and check_collision(ship_x, ship_y, ship_w, ship_h,
                                       boss.x, boss.y, boss_w, boss_h) then
        game_over = true
        return
    end

    -- Move stars
    for i, star in ipairs(stars) do
        star.y = star.y + star.speed * dt
        if star.y > SCREEN_H then
            star.x = math.random(0, SCREEN_W)
            star.y = -star.size
        end
    end
end

local function draw()
    canvas.clear()

    -- Dark space background
    canvas.set_color(10, 10, 30)
    canvas.fill_rect(0, 0, SCREEN_W, SCREEN_H)

    -- Stars
    for i, star in ipairs(stars) do
        canvas.set_color(star.brightness, star.brightness, star.brightness)
        canvas.fill_rect(star.x, star.y, star.size, star.size)
    end

    -- Lasers
    for i, laser in ipairs(lasers) do
        canvas.draw_image("laser", laser.x, laser.y, laser_w, laser_h)
    end

    -- Meteors
    for i, meteor in ipairs(meteors) do
        canvas.draw_image("meteor", meteor.x, meteor.y, meteor_w, meteor_h)
    end

    -- Enemy lasers
    for i, laser in ipairs(enemy_lasers) do
        canvas.draw_image("enemy_laser", laser.x, laser.y, laser_w, laser_h)
    end

    -- Enemies
    for i, enemy in ipairs(enemies) do
        canvas.draw_image("enemy", enemy.x, enemy.y, enemy_w, enemy_h)
    end

    -- Boss
    if boss ~= nil then
        canvas.draw_image("boss", boss.x, boss.y, boss_w, boss_h)
    end

    -- Ship
    canvas.draw_image("ship", ship_x, ship_y, ship_w, ship_h)

    -- HUD
    canvas.set_color(255, 255, 255)
    canvas.set_font_size(16)
    canvas.draw_text(10, 10, "Score: " .. score)
    canvas.draw_text(10, 30, "Wave: " .. wave)
    canvas.draw_text(10, 50, "Arrow keys: Move | SPACE: Shoot")

    -- Boss health bar
    if boss ~= nil then
        local bar_w = 300
        local bar_x = (SCREEN_W - bar_w) / 2
        canvas.set_color(60, 60, 60)
        canvas.fill_rect(bar_x, 15, bar_w, 14)
        canvas.set_color(220, 40, 40)
        canvas.fill_rect(bar_x, 15, bar_w * boss.hp / boss.max_hp, 14)
    end

    -- Wave banner
    if wave_state == "banner" and not game_over then
        canvas.set_font_size(48)
        canvas.set_color(255, 220, 80)
        local banner = "WAVE " .. wave
        if boss ~= nil then
            banner = "BOSS WAVE!"
        end
        local banner_w = canvas.get_text_width(banner)
        canvas.draw_text((SCREEN_W - banner_w) / 2, SCREEN_H / 2 - 24, banner)
    end

    -- Game over overlay
    if game_over then
        -- Dark overlay
        canvas.set_color(0, 0, 0, 180)
        canvas.fill_rect(0, 0, SCREEN_W, SCREEN_H)

        -- "GAME OVER" text (red)
        canvas.set_font_size(48)
        canvas.set_color(255, 50, 50)
        local title = "GAME OVER"
        local title_w = canvas.get_text_width(title)
        canvas.draw_text((SCREEN_W - title_w) / 2, SCREEN_H / 2 - 60, title)

        -- Score text (white)
        canvas.set_font_size(24)
        canvas.set_color(255, 255, 255)
        local score_text = "Score: " .. score
        local score_w = canvas.get_text_width(score_text)
        canvas.draw_text((SCREEN_W - score_w) / 2, SCREEN_H / 2, score_text)

        -- Restart prompt (white)
        local restart_text = "Press ENTER to restart"
        local restart_w = canvas.get_text_width(restart_text)
        canvas.draw_text((SCREEN_W - restart_w) / 2, SCREEN_H / 2 + 40, restart_text)
    end
end

-- ============================================================
-- GAME LOOP
-- ============================================================

local function game()
    user_input()
    update()
    draw()
end

canvas.tick(game)
canvas.start()
